# 每日任务技能

## When to Use

当用户请求以下操作时使用此技能：
- "每日任务"、"日常任务"、"做每日"
- "做一下每日"、"每日"、"日常"
- "everyday"、"daily"、"daily mission"
- "帮我做每日任务"
- 需要自动完成崩坏3每日全部操作

## 概述

此技能调用 hongkai 模块的 `everyday.py` 脚本，自动完成每日任务全流程：

1. 登录领取（每日签到奖励）
2. 金币领取
3. 出击一键减负
4. 舰团功能（捐赠、领取）
5. 家园打工、领取
6. 任务奖励领取

## 技能流程

此技能为单步执行，无需分阶段。

**步骤 1** — 调用 `run_hongkai_task task="everyday"`

调用 `run_hongkai_task task="everyday"` 启动每日任务自动化脚本。该脚本会：
1. 请求管理员权限（如未提权）
2. 聚焦崩坏3游戏窗口
3. 启动视频录制
4. 依次完成登录领取、金币领取、出击减负、舰团、家园、任务奖励
5. 完成后返回主界面并停止录制

脚本会弹出新控制台窗口，用户可观察执行进度。最长等待 600 秒。

**步骤 2** — 报告结果

根据工具返回结果向用户汇报完成情况和日志摘要。

## 前置条件

1. **游戏需在主界面**（舰桥）
2. **需要管理员权限**
3. **执行时间**：约 5-10 分钟
