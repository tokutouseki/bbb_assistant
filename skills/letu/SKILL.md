# 往世乐土自动化技能

## When to Use

当用户请求以下操作时使用此技能：
- "打乐土"、"往世乐土"、"乐土周常"
- "letu"、"elysian realm"、"Elysian Realm"
- "帮我打乐土"
- 需要自动完成往世乐土全部流程

## 概述

此技能调用 hongkai_done 的 `letu.py` 脚本，自动完成往世乐土全流程：

1. 从主界面 → 出击 → 挑战 → 往世乐土
2. 进入深层序列
3. 回放键盘宏配置关卡选择
4. 减负战斗
5. 神之键配置
6. 追忆之证配置
7. 启动爱莉希雅战斗 AI（全自动战斗+刻印选择+商店购买+路径寻找）

## 技能流程

此技能为单步执行，无需分阶段。

**步骤 1** — 调用 `run_hongkai_task` 执行往世乐土

调用 `run_hongkai_task task="letu"` 启动往世乐土自动化脚本。该脚本会：
1. 请求管理员权限（如未提权）
2. 聚焦崩坏3游戏窗口
3. 启动视频录制
4. 依次完成导航、配置、战斗全流程
5. 战斗结束后返回主界面并停止录制

脚本会弹出新控制台窗口，用户可观察执行进度。最长等待 600 秒。

**步骤 2** — 报告结果

根据工具返回结果向用户汇报：
- 完成情况（成功/失败/超时）
- 执行的日志摘要

## 前置条件

1. **首次运行需要配置**：
   - `reproduce/letu_level.json`：乐土关卡选择的键盘宏录制文件
   - `reproduce/zhuiyizhizheng.json`：追忆之证配置的键盘宏录制文件
   - 这两个文件只需配置一次，后续运行会使用 `config.json` 中的 `letu_level_done` 和 `zhuiyizhizheng_done` 标记跳过

2. **角色要求**：默认使用爱莉希雅（Elysia），战斗 AI 在 `character/letu_elysia_star.py` 中定义

## 注意事项

1. **需要管理员权限**：脚本会自动请求 UAC 提权
2. **游戏必须已打开**：确保崩坏3游戏在主界面（舰桥）
3. **执行时间**：完整乐土流程约 10-20 分钟
4. **视频录制**：脚本会自动录制操作过程（640×360, 30fps），保存在视频日志目录
5. **新窗口弹出**：脚本会在新控制台窗口中运行
6. **配置文件持久化**：首次配置的关卡选择和追忆之证会被记住，后续运行自动跳过
