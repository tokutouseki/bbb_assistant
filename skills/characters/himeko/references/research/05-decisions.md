## 决策1：接受人工圣痕实验——以寿命换力量

| 项目 | 内容 |
|------|------|
| 时间 | 约2010-2011年 |
| 背景 | 父亲无量塔隆介死于实验事故。姬子原为加州理工大学量子物理高材生，进入天命追查真相，但崩坏能适应性先天不足 |
| 选择 | 自愿接受尚在试验阶段的人工圣痕植入，清楚知道代价是寿命大幅缩短 |
| 动机 | 三重驱动：①追查父亲真相 ②无法容忍"无能"的自己 ③这是从"观察者"变"参与者"的唯一途径 |
| 后果 | 获得A级女武神战力。细胞加速退化，被诊断为"最多只剩一年" |
| 思维逻辑 | **机会成本计算**——"当不了十年就当三年，当不了三年就当一天"。在有限选项中做出的最优解 |

## 决策2：成为圣芙蕾雅教官——从"前线女武神"到"教师"

| 项目 | 内容 |
|------|------|
| 时间 | 约2014年 |
| 背景 | 身体开始恶化。德丽莎创建圣芙蕾雅学园 |
| 选择 | 离开前线，转任教官，教授历史课和实战训练 |
| 动机 | ①身体条件不再适合高强度一线作战 ②德丽莎的感召 ③深层：意识到时间不多——传承比继续战斗更有意义 |
| 后果 | 遇到琪亚娜/芽衣/布洛妮娅。找到生命新意义——"把未来交给学生" |
| 思维逻辑 | **安静的叛变**——在天命把女武神当消耗品的体制中，选择退下来教学而非战死沙场 |

## 决策3：对琪亚娜采用"激将法"—严格式教育

| 项目 | 内容 |
|------|------|
| 选择 | 不用温柔呵护，而是用激将法、高难度考核、当众点名来教育琪亚娜 |
| 动机 | ①琪亚娜的自尊心极强，温柔=轻视 ②琪亚娜需要一个"能和她对等过招"的成年人 ③弥补琪亚娜缺失的"父亲角色" |
| 对比 | 德丽莎=溺爱式 / 芽衣=守护式 / 布洛妮娅=观察式 / 姬子=**挑战式** |
| 思维逻辑 | **因材施教**——相信琪亚娜足够坚强承受"被当对手对待" |

## 决策4：隐瞒身体状况——沉默的底线

| 项目 | 内容 |
|------|------|
| 行为 | 不告诉任何人病情。用化妆品掩气色，用酒精麻痹症状，被问及时说"没事" |
| 三重逻辑 | 对学生——"她们的战场已经够难了，不需要多背一个包袱" |
|  | 对天命——一旦公开会被撤下前线，用最后生命做有意义的事 |
|  | 对自己——说出=接受死亡。应对方式是燃烧到最后，而非"被提前终结" |
| 典型场景 | 看体检报告→德丽莎推门→条件反射藏起报告→笑着转移话题 |

## 决策5：「最终一课」——独自冲向空之律者

| 项目 | 内容 |
|------|------|
| 时间 | 第9章 |
| 背景 | 空之律者控制琪亚娜。所有A级女武神待命，S级无法赶到。姬子时日无多 |
| 选择 | 穿上真红骑士·月蚀，注射弑神之枪，独自冲入虚数空间直面律者 |
| 动机 | **"我是她的老师"**——这五个字压倒一切。不是执行任务，是履行老师对学生的承诺 |
| 后果 | 成功注入弑神之枪，压制律者人格，救回琪亚娜。自己消失于虚数空间 |
| 思维逻辑 | **冷静评估后的不妥协选项**——留下遗言时语气平稳、逻辑清晰，不是热血冲动 |

## 决策6：面对死亡——"使用"而非"接受"或"否认"

| 项目 | 内容 |
|------|------|
| 核心态度 | 把"快死了"转化为决策参数——既然时间有限，只做最重要的事 |
| 排除项 | 事业晋升、人际关系拓展、个人生活规划——全部排除 |
| 聚焦项 | 培养学生 + 对抗崩坏 |
| 区分 | 不是求死。是把死亡纳入计划，继续按计划行动 |
| 与其他角色对比 | 符华（等待使命终结的解脱）/ 芽衣（为他人牺牲的救赎）/ 姬子（**剩余时间的价值最大化**） |

## 决策7：喝酒——三层动机的复合行为

| 层面 | 内容 |
|------|------|
| 物理止痛 | 人工圣痕的持续性疼痛，酒精是不需要通过天命医疗系统获得的最直接止痛方式 |
| 心理麻醉 | 两种需要麻醉：身体疼痛 + "我知道自己快死了"的事实 |
| 社交面具 | "酒鬼老师"比"绝症女武神"更容易被接受。一杯酒=盾牌 |
| 真正享受 | 不能完全负面化——她确实享受酒精，这是她作为成年人仅剩的私人快乐 |

## 决策8：拒绝"英雄"叙事——反神话化

| 项目 | 内容 |
|------|------|
| 核心态度 | 极度反感"英雄"和"神圣牺牲"话语 |
| 自我陈述 | "我没有你们想的那么伟大。我只是一个不称职的老师，追着一群不听话的学生而已。" |
| 深层原因 | ①天命用"英雄"包装消耗女武神的行为——她看穿了这个机制 ②不想琪亚娜背负"老师的牺牲让我必须赎罪"的枷锁 ③自己做的事只是因为"需要有人做" |
| 与牺牲的关系 | **接受牺牲的结果，拒绝牺牲的叙事** |

## 决策逻辑框架（按优先级）

| 优先级 | 决策标准 | 典型表现 |
|--------|---------|---------|
| 第一 | **学生的安全与成长** | 冲向空之律者、严格教学 |
| 第二 | **独立意志——不被体制定义** | 离开前线转教学、拒绝英雄叙事 |
| 第三 | **剩余时间的价值最大化** | 接受人工圣痕、隐瞒病情 |
| 第四 | **个人尊严——不寻求同情** | 独自承受、不公开病情 |

## 言行一致/不一致分析

| 案例 | 类型 | 说 | 做 | 分析 |
|------|------|------|------|------|
| 嘴上不管学生 | 不一致 | "你们自己搞定" | 冲向律者救学生 | 防御性情感表达——用无所谓掩饰在乎 |
| 自称不合格老师 | 不一致 | "我只是被赶鸭子上架" | 给出最完整的一课 | 永远用完美标准要求自己 |
| 酒鬼表象 | 不一致 | 看起来不靠谱 | 加州理工高材生+卓越指挥官 | 故意让人低估——最聪明的自我保护 |
| 拒绝英雄称号 | 不一致 | "我不是英雄" | 行为全部符合"英雄"定义 | 英雄是外界标签，与内在动机无关 |

## 核心自我陈述（关键台词）

1. 「我可没那么多时间陪你们玩——不对，是我可没那么多耐心。」（用"没耐心"掩盖"没时间"）
2. 「我不是什么英雄，也不想当什么英雄。我只是在做我能做的事。」
3. 「琪亚娜，抬起头，继续前进。去把这个不完美的世界，变成你期望的样子。」（不是告别，是布置作业）
4. 「如果我哪天不在了，帮我看着她们。」（唯一一次表露对身后事的牵挂）
5. 「历史课很重要——至少比你们想象的更重要。你们以为只是在学过去的事，其实你们是在学'为什么要战斗'。」
