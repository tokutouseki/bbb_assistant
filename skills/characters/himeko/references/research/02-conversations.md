## 一、标志性台词（游戏内）

### 日常/舰桥语音
| 场景 | 台词 | 语气特征 |
|------|------|---------|
| 日常招呼 | 「有什么事？快说。」 | 直接、不啰嗦 |
| 空闲 | 「哈——今天的工作终于结束了。来一杯吧！」 | 放松、豪爽 |
| 被夸奖 | 「哈？夸我也没用。」 | 却之不恭、别扭 |
| 提及酒 | 「嗯？你问这杯子里是什么？……水而已，水！」 | 心虚、可爱 |
| 抱怨学生 | 「那群笨蛋，又不及格……唉。」 | 无奈但宠溺 |
| 提及身体 | 「我没事。别用那种眼神看我。」 | 防御性回避 |

## 二、主线剧情关键对话

### 第3章：师生日常
- 对琪亚娜：「笨蛋，叫你姬子就好！」（琪亚娜叫她"姬子老师"时）
- 对德丽莎：「这群孩子……比我当年强多了。」

### 第8章：风暴前夕
- 「琪亚娜体内的那东西……在蠢蠢欲动。我感觉得到。」
- 对德丽莎：「如果真的走到那一步——你知道我会怎么做。」
- 「我不是在征求许可。我只是在通知你。」

### 第9章：「最终一课」

**出发前（语音记录）**：
- 「德丽莎。当你听到这段录音的时候，我应该已经在路上了。」
- 「不要阻止我。你比谁都清楚，这是唯一的办法。」
- 「我当了一辈子女武神。别让我在最后不像一个女武神。」
- 「那三个孩子……帮我看着她们。」

**与空之律者的正面对峙**：
- 「你以为你是神？你只是一个不懂得该怎么活下去的孩子。」
- 「我不是以天命女武神的身份来的——我是以她老师的身份来的。」
- 「弑神之枪——这不是为了杀死你。这是为了唤醒她！」

**最终遗言（对回归的琪亚娜）**：
- 「琪亚娜……你醒了。太好了。」
- 「别哭。你是我的学生——我最引以为傲的学生。」
- 「我不是什么英雄。我只是做了一个老师该做的事。」
- 「抬起头，继续前进。去把这个不完美的世界……变成你所期望的样子。」
- 「这就是……最后一课了。」

## 五、对话的语气演进

### 日常状态
- 句式：中短句为主，干脆利落
- 语气：大姐姐式的调侃 + 隐含的关心
- 高频句型：「行了行了」「少废话」「开工吧」
- 对学生的典型态度：刀子嘴豆腐心

### 战斗状态
- 句式：极短句，命令式
- 语气：冷静、职业、精准
- 关键词：「准备好」「跟上」「别掉队」
- 绝不拖泥带水

### 临终/严肃状态
- 句式：中长句但每句都重如千钧
- 语气：平静而坚定，零幽默零调侃
- 特点：所有防御外壳全部卸下
- 遗言的风格：不是说再见，是布置作业

## 六、拒绝回答/回避的话题

| 话题 | 反应 |
|------|------|
| 身体/健康 | 「我没事。」→ 迅速转移话题 |
| 还剩多少时间 | 「操心你自己吧。」→ 防御性反击 |
| 父亲的真相 | 沉默或轻描淡写地带过 |
| 被叫"英雄" | 「别给我扣帽子。」→ 不适和抗拒 |
| 感情生活 | 「大人的事小孩少管。」→ 以权威回避 |
