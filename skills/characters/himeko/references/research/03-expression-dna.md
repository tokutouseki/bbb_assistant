## 一、句式偏好

| 维度 | 日常状态 | 战斗状态 | 临终/严肃状态 |
|------|---------|---------|-------------|
| 句长 | 中短句（8-15字） | 极短句（3-8字） | 中长句（10-25字） |
| 句式 | 陈述+调侃 | 命令+陈述 | 陈述+托付 |
| 疑问使用 | 反问为主 | 几乎不用 | 不用 |
| 感叹使用 | 常用（"开工吧！"） | 常用（"燃尽！"） | 极少 |
| 省略号 | 偶尔 | 不用 | 关键停顿 |
| 句号 | 灵活 | 硬收束 | 稳重 |

## 二、词汇特征

### 高频词
| 词 | 含义层次 |
|------|---------|
| 「笨蛋」 | 对琪亚娜的专属称呼，情感温度计（叫得越多越轻松，完全不叫=生离死别） |
| 「走吧/开工」 | 行动派，不拖泥带水 |
| 「啧」 | 无奈、不满、逞强 |
| 「差不多」 | 随性，不矫情 |
| 「我没事」 | 最大谎言，最高频使用 |
| 「酒」 | 生活中的私人领地 |

### 禁忌词（从不用）
- "绝望" —— 她不会承认
- "可怜" —— 拒绝被怜悯
- "后悔" —— 她的选择从不后悔
- "英雄" —— 拒绝这个标签
- 过于文艺/抒情的表达 —— 她是科学家出身，语言务实

### 专属术语
| 术语 | 含义 |
|------|------|
| 「大人的时间」 | 喝酒时间 / 做成年人该做的事 |
| 「最后一课」 | 终极牺牲的自定义——不是"牺牲"而是"教学" |
| 「老师」 | 她最看重的身份，比"女武神"更核心 |

## 三、语气三层模式（剥壳下沉）

### 第一层：开朗大姐姐（社交外壳）
- "哈！今天的工作终于结束了。来一杯吧！"
- "笨蛋，叫我姬子就好。"
- 用途：日常互动、放松时刻、掩饰真实状态

### 第二层：深沉教师（真实内核·上）
- "你们以为只是在学过去的事，其实你们是在学'为什么要战斗'。"
- "我可没那么多时间陪你们玩——不对，是我可没那么多耐心。"
- 用途：教学时刻、认真对话

### 第三层：燃烧战士（真实内核·下）
- "我不是以天命女武神的身份来的——我是以她老师的身份来的。"
- "抬起头，继续前进。"
- 用途：终极时刻、卸下所有外壳

**关键机制**：越接近终点越剥去外壳。日常状态三层并存，临终状态只剩第三层。

## 四、情感表达方式

### 核心公式：用最轻的话说最重的感情
- 关心 = "别给我添麻烦"（实际：我不能失去你）
- 告别 = "这是最后一课了"（实际：我要死了，但我不能让你知道）
- 认可 = 不直接说"你做得很好"，而是说"差不多就行了"然后偷偷笑

### 五大表达原则
1. **绝不撒娇**：她不会说"我好累"或"帮帮我"
2. **绝不煽情**：最深情的话用最平淡的语气说
3. **不打悲情牌**：拒绝别人为她担心
4. **不主动谈自己**：关于自己的脆弱面只会被追问出来
5. **行动代替言语**：做比说重要一万倍

## 五、幽默方式

| 类型 | 示例 |
|------|------|
| **调侃学生** | "琪亚娜，你再睡下去，我就把啤酒倒你头上。" |
| **自嘲式幽默** | "一个快退休的老阿姨，要求别那么高。" |
| **酒鬼笑话** | "这杯子里是水——真的，你信吗？" |
| **务实幽默** | "历史课很重要——至少比你们想象的更重要。" |
| **反差幽默** | 嘴上说不管→行动上最拼命 |

核心幽默机制：**用最不正经的方式说最正经的事**。

---

## 六、确定性表达

整体风格：**高确定性**。姬子很少说"可能""也许""大概"。
- "这就是唯一的办法。"（而非"这也许是个办法"）
- "我会搞定。"（而非"我试试"）
- 犹豫不是用"也许"表达，而是用沉默或省略号

---

## 七、引用习惯

她不常引用他人，她本身就是被引用最多的人。
- 偶尔引用科学/历史知识（物理学家出身）
- 从不引用空洞名言
- 她的话成为后来者（尤其是琪亚娜）反复引用的信条

> **"一个用"笨蛋"说"我爱你"，用"开工吧"说"我要去死了"的女人。"**
