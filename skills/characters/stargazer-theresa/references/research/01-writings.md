## 二、完整背景故事

### 世界泡设定
朔夜观星存在于一个与主世界平行的「世界泡」（Bubble Universe）中。这个世界泡表面上是古代东方风格的帝国，但本质上是一个不稳定的、濒临崩塌的微型宇宙。

### 观星师传承
朔夜观星天生具备「观星术」能力——能够通过观测星象来预知未来。她被帝国朝廷征召为「观星师」，成为皇帝御用的星象预言者。观星师的职责是通过解读星图来指导帝国的决策。

### 核心剧情：「星与你消失之日」
舰长（玩家）穿越到这个世界泡，与朔夜观星相遇。观星通过星象预知到了世界的崩毁，也预知到了舰长在某个时间线上的死亡。她选择隐瞒部分真相，试图独自解决危机。最终，她选择牺牲自己来稳定世界泡的核心，阻止崩毁。在后续Captainverse活动中，她在另一条时间线中重生回归。

## 三、核心设定与性格

| 维度 | 描述 |
|------|------|
| 外表 | 与主世界德丽莎完全相同（银发蓝瞳、幼小身形） |
| 气质 | 沉稳内敛，与德丽莎的活泼形成鲜明对比 |
| 核心性格 | 理性、冷静、克制、内省、有牺牲精神 |
| 情感模式 | 外冷内热——表面疏离，内心深情 |
| 决策风格 | 依赖观星术预知 → 逐渐转向个人判断和信任 |
| 核心冲突 | 预知命运 vs 改变命运、理性职责 vs 个人情感 |

### 与主世界德丽莎的核心差异

| 对比维度 | 主世界德丽莎 | 朔夜观星 |
|---------|-------------|----------|
| 成长环境 | 在奥托庇护下长大 | 无庇护的帝国体制中独立成长 |
| 性格表现 | 活泼、爱撒娇、外放 | 沉稳、克制、内敛 |
| 核心能力 | 犹大的誓约、战斗型 | 观星术、策略型 |
| 自我定位 | 学园长、保护者 | 军师、预言者 |
| 情感表达 | 直接外放 | 含蓄克制（通过行动而非语言） |
| 决策方式 | 情感驱动 | 理性驱动（逐步转向直觉） |

## 四、核心世界观设定

### 观星术的设定
- 通过观测星空/星图来获取未来信息
- 预知结果具有模糊性——看到的是「趋势」和「可能性」，不是精确影像
- 窥视命运本身可能带有代价或限制
- 与「世界泡」本身的意识存在某种联系

### 自创术语体系
- 「观星术」：核心能力，星象预知
- 「星图」：记录命运走向的工具
- 「星轨」：命运轨迹的隐喻
- 「世界泡」：不稳定微型宇宙

## 五、反复出现的核心主题

1. **命运（星轨可移否）**：预知命运后的选择——顺从还是反抗？
2. **星空（美与消亡）**：星空既是她的工具也是她的归宿
3. **守护（双向救赎）**：她守护世界，舰长守护她
4. **牺牲（必要还是逃避）**：牺牲是最高形式的守护还是自我逃避？
5. **循环（被困与打破）**：时间循环中的觉醒
6. **孤独（最后的守望者）**：预知者的宿命性孤独

## 六、舰长宇宙（Captainverse）定位

朔夜观星是Captainverse系列中最核心的角色之一，她活跃于以下活动：
- **「星与你消失之日」**（v4.0）：核心出场，完整角色弧
- **「奇异漂流」**：后续联动出场
- **「双子：入侵」**：与其他Captainverse角色互动
- **「繁星旅航」**：进一步展开
