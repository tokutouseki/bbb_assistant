# 05-decisions.md - 朔夜观星 关键决策记录

> 调研时间：2026年5月26日

## 七大关键决策

### 决策1：成为帝国观星师
| 维度 | 内容 |
|------|------|
| 背景 | 天生具备观星术能力，被帝国朝廷征召 |
| 决策 | 接受观星师职位，进入帝国体制 |
| 逻辑 | 获取身份和资源，在体制内发挥影响 |
| 代价 | 被体制约束，预言必须服务于政治需要 |
| 一致性 | ★★★★☆ |

### 决策2：预言世界崩毁后选择沉默
| 维度 | 内容 |
|------|------|
| 背景 | 通过观星术预知世界泡终将崩毁 |
| 决策 | 不完全公开预言，独自承担 |
| 逻辑 | 公开只会制造恐慌；深层的逃避——说出来也改变不了 |
| 代价 | 独自背负世界终末的秘密，形成内敛疏离的性格 |
| 一致性 | ★★★☆☆ 表面一致但内心矛盾 |

### 决策3：隐瞒舰长的死亡预知 ★★
| 维度 | 内容 |
|------|------|
| 背景 | 预知到某个时间线上舰长的死亡/消失 |
| 决策 | 不告诉舰长，独自尝试改变这一命运 |
| 逻辑 | 保护舰长 + 不愿承认自己「关心」舰长 |
| 代价 | 行动不透明，舰长无法理解她的动机 |
| 一致性 | ★★☆☆☆ 最大的言行不一致 |

### 决策4：牺牲自己阻止世界崩塌 ★★★
| 维度 | 内容 |
|------|------|
| 背景 | 世界泡崩毁进入倒计时 |
| 决策 | 以自身存在为代价稳定世界泡核心 |
| 逻辑 | 表层：职责所在；深层：守护舰长和值得守护的世界 |
| 代价 | 自身存在被从时间线中抹去 |
| 一致性 | ★★★★★ 完全一致 |

**转折意义**：这是她第一次不完全依赖观星术、而是依靠自己的意志做出决定。

### 决策5：接受重生/复活——选择回来 ★★
| 维度 | 内容 |
|------|------|
| 背景 | 舰长在多个世界泡之间的穿梭创造了重生契机 |
| 决策 | 选择「回来」——重新与舰长和世界建立联结 |
| 逻辑 | 从职责驱动→情感驱动：「你的存在让这个世界值得回来」 |
| 代价 | 不再完全是「原来」的观星 |
| 一致性 | ★★★★☆ |

### 决策6：放弃纯理性立场——信任舰长 ★★
| 维度 | 内容 |
|------|------|
| 背景 | 舰长是观星术无法预测的「异常变量」 |
| 决策 | 放弃用观星术评估舰长，基于相处经验信任他 |
| 逻辑 | 观星术对舰长失效→必须以「普通人」的方式信任 |
| 代价 | 等同于自愿「失明」——放弃最依赖的工具 |
| 一致性 | ★★★★★ |

### 决策7：从「接受命运」到「超越命运」
| 维度 | 内容 |
|------|------|
| 背景 | 观星术的核心悖论——预知→想改变→改变了就证明预知错误 |
| 决策 | 选择拥抱不确定性，将观星术从「指南针」降级为「参考工具」 |
| 逻辑 | 放弃对「绝对正确」的执念，选择「有意义地活着」 |
| 代价 | 某种意义上「背叛」了观星师的身份——但对她而言是解放 |
| 一致性 | ★★★★☆ |

---

## 决策模式演变

```
前期：观星术预知 → 理性分析 → 按「最正确」方案行动
       ↓（舰长介入）
后期：直觉感知 → 关系考量 → 按「最有意义」方案行动
```

### 决策优先级变化

| 优先级 | 前期（观星师模式） | 后期（个人模式） |
|--------|-------------------|-----------------|
| 1 | 观星术预言 | 守护重要之人 |
| 2 | 帝国职责 | 直觉和个人判断 |
| 3 | 个人安全 | 观星术（降级为参考） |
| 4 | 情感和直觉（被压抑） | 职责（退居次要） |

---

## 核心洞察

朔夜观星的角色弧本质上是**从「观星术的囚徒」成长为「自己命运的主人」**。她的言行不一致（声称遵循预言却实际抗争命运）不是角色缺陷，而是她作为「人」的真实性的核心体现。
