## 二、完整背景故事

### 阶段一：童年——普通女孩（约1985-1990年代初）

西琳出生于西伯利亚的一个小村庄，与母亲相依为命。童年早期生活朴素但幸福。母亲因病去世后，西琳第一次体验了「失去所爱之人」的痛苦。随后被天命带走，送往巴比伦实验室。

**核心主题**：失去母亲的创伤是西琳所有后续行为的底层情感根源。

### 阶段二：巴比伦实验室——地狱（约1995-1999年）

巴比伦实验室由奥托·阿波卡利斯幕后操控，表面上是一个研究设施，实为对儿童进行崩坏适应性实验的残酷场所。

西琳在此结识了四位朋友：**贝拉**（最亲密）、**加莉娜**、**阿芙罗拉**、**阿加塔**。实验越来越残酷，朋友们一个接一个地死于实验。贝拉是最后一个死去的——她的死亡让西琳精神彻底崩溃。

**核心主题**：被背叛感、无力保护所爱之人的愧疚、对人类世界的绝望。

### 阶段三：律者觉醒与第二次崩坏（2000年2月）

在巴比伦实验室深处，崩坏意志以「神」的身份接触西琳，许诺让她与母亲重逢。西琳接受力量，觉醒为空之律者。被赋予5颗律者宝石（空、雷、风、炎、死）。用律者核心「复活」死去的朋友们，创造拟似律者。

随后发动第二次崩坏战争，击败第一律者瓦尔特·杨，与天命/逆熵联军全面开战。最终在月球上被塞西莉亚与齐格飞联手击败，与塞西莉亚同归于尽。

**核心主题**：复仇、渴望母爱、力量即正义、孤独的终极代价。

### 阶段四：意识存续与K-423（2000-2017年）

奥托回收西琳核心，植入克隆体K-423中。西琳意识以「律者人格」形式存在于琪亚娜（K-423）体内。2010年首次暴走（齐格飞失去左臂）；2016年完全觉醒（姬子牺牲，空之律者再临）；2017年千人律者事件中与琪亚娜达成和解。

## 三、魔法少女西琳的来源

魔法少女西琳是2019年夏季活动中推出的圣痕套装和SP角色。定位为「平行世界/IF线」——如果西琳不是律者而是一个普通的魔法少女，会是什么样？

**设计理念**：以上世纪经典魔法少女动画风格呈现——变身、魔法棒、爱心攻击、傲娇口头禅。

**与主线的关系**：明确是平行世界，不影响正史。但两种形态共享相同的底层需求：渴望被爱、害怕孤独。

## 四、核心设定与性格

### 主线西琳的性格特征

| 层面 | 表现 |
|------|------|
| **童年** | 善良、渴望母爱、容易相信、但内心已有"不被需要"的创伤 |
| **实验室时期** | 坚定、温暖（对朋友）、恐惧、孤独（深夜） |
| **律者时期** | 傲慢、冷酷、蔑视、嘲弄——"空之女王"防御性人格 |
| **与塞西莉亚相遇** | 困惑、动摇、渴望、哭泣——脆弱面短暂暴露 |
| **K-423残留意志** | 仇恨惯性、不甘——"凭什么只有我要承受这些？" |

### 魔法少女西琳的性格特征

| 层面 | 表现 |
|------|------|
| **外表** | 活泼、傲娇、中二、戏剧化 |
| **内心** | 渴望被认可、需要朋友、想要被关注 |
| **行为** | 口是心非的典型傲娇——嘴上说不要，身体很诚实 |

### 核心价值观公式

> 被背叛 → 仇恨 → 复仇 → 孤独 → 渴望爱 → 被理解 → 安息

## 六、已知矛盾（保留不调和）

1. **「我恨人类」vs 渴望人际关系**：嘴上说恨人类，行动上却用全部力量构建「朋友永远在一起」的假象
2. **「力量就是一切」vs 力量无法满足对爱的渴望**：拥有毁灭世界的力量，却在塞西莉亚的温柔下哭泣
3. **拒绝救赎 vs 渴望被救赎**：推开塞西莉亚的手，但最终在琪亚娜的理解中得到安息
4. **「女王」身份 vs 「孩子」本质**：自称空之女王，但所有行为的底层动机都是「想要妈妈」
5. **魔法少女西琳的正史定位**：明确为平行世界，但与主线西琳共享同样的情感核心
