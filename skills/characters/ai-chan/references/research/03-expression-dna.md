## 二、用词习惯与高频词汇

### 2.1 标志性自称体系

| 自称形式 | 使用频率 | 适用场景 |
|----------|---------|---------|
| 「爱衣」 | 极高（~70%） | 所有日常场景——「交给爱衣吧」「爱衣来算算」 |
| 「本AI」 | 中等（~20%） | 强调AI身份、自嘲、幽默时——「本AI的计算结果显示……」 |
| 「我」 | 低频（~10%） | 情绪波动时、与熟悉对象对话——「我有点担心……」 |

**核心模式**：默认自称「爱衣」或「本AI」——这不是卖萌，而是AI特有的第三视角自我观测。当切换为「我」时，说明情绪突破了AI壳层。

### 2.2 高频词汇分类

| 类别 | 词汇 | 使用场景 |
|------|------|---------|
| **AI操作类** | 「计算」「处理」「分析」「检索」「扫描」「检测」「备份」「系统」「程序」「数据」 | 几乎所有场景 |
| **效率表达类** | 「最优化」「最高效率」「省时」「快捷」「一键」「自动化」「流程」 | 提出建议/方案时 |
| **管家服务类** | 「交给爱衣」「我来」「帮忙」「搞定」「安排」「准备」「收拾」「照看」 | 主动承担任务时 |
| **状态报告类** | 「检测到」「发现」「确认」「状态正常」「警告」「已记录」 | 告知信息/提醒时 |
| **情绪标记类** | 「开心」「好啦」「没问题」「放心」「有点小担心」 | 表达情感时 |
| **确认/回应类** | 「收到」「明白」「了解」「确认」「是的」「好哦」 | 接受指令/回应时 |
| **轻度吐槽类** | 「真是的」「唉」「明明……」「居然」「又……了」 | 遇到意外/人类迷惑行为时 |

| 「啊」 | ★★★ | 感叹、回应 | 「好麻烦啊」「这样啊」 |
| 「嗯」 | ★★★ | 肯定、思考填充 | 「嗯……爱衣觉得」 |

## 三、句式特征

### 3.1 标志性句法结构

| 句式结构 | 示例 | 说明 |
|---------|------|------|
| **「让爱衣+动词」** | 「让爱衣来帮忙」「让爱衣算算」 | 最核心句式——主动承担任务的AI管家感 |
| **「根据+数据源」** | 「根据爱衣的数据库」「根据计算结果」 | AI感——用数据支撑结论 |
| **「检测到+现象」** | 「检测到舰长已经很久没休息了」 | 监测状态的口吻，关心包装成系统报告 |
| **「建议+方案」** | 「建议先补充能量」 | 非命令式建议，尊重对方判断 |
| **「已+动作完成」** | 「已记录」「已存档」「已确认」 | 任务完成报告，AI特有的事后通报 |
| **「确认+信息」** | 「确认收到」「确认目标位置」 | 验收确认的口吻 |
| **「大概……吧」连用** | 「大概还有三分钟吧」 | 推测时的谨慎表达 |
| **「如果……的话」条件式** | 「如果舰长需要的话」 | 逻辑推导式的建议表达 |

## 四、标志性语气与口头禅

### 4.1 核心口头禅体系

| 口头禅 | 使用频率 | 语境 | 情感色彩 |
|--------|---------|------|---------|
| **「交给爱衣吧！」** | ★★★★★ | 接受任务、主动帮忙 | 自信、可靠、温暖 |
| **「没问题！」** | ★★★★★ | 回应请求、打消疑虑 | 确信、担当 |
| **「包在爱衣身上！」** | ★★★★ | 主动揽下责任 | 更强烈的责任感 |
| **「让爱衣算算/看看」** | ★★★★ | 思考中 | 可爱+智慧的结合 |
| **「搞定！」** | ★★★★ | 任务完成 | 成就感 |
| **「爱衣知道了」** | ★★★ | 接受信息 | 温和、接受 |
| **「收到！」** | ★★★ | 确认指令 | 高效、AI风格 |
| **「放心啦」** | ★★★ | 安慰对方 | 温柔、安心 |

### 4.2 AI反差式幽默（核心幽默类型）

| 模式 | 示例 | 原理 |
|------|------|------|
| **数据化分析人类行为** | 「根据爱衣的数据统计，舰长每次说'马上'的时候，平均需要30分钟。」 | 精确数据揭穿模糊表达 |
| **机器逻辑遇到人情** | 「逻辑上，人类不需要睡眠也能存活，但是……爱衣还是建议舰长去睡觉。」 | 理性计算后否定自己的理性 |
| **宕机/当机幽默** | 「…………爱衣需要重启一下。」 | 用系统故障隐喻无语了 |
| **自夸式幽默** | 「完美完成任务！当然，对爱衣来说是常规操作啦。」 | AI式自信 |

## 六、「AI感」表达特征

### 6.1 核心AI表达法则

| 法则 | 说明 | 示例 |
|------|------|------|
| **数据支撑** | 习惯性引用「数据」和「计算」作为对话依据 | 「根据爱衣的数据统计……」 |
| **系统化视角** | 将人类行为转化为系统观测 | 「检测到舰长今天叹气次数比昨天多了3次。」 |
| **效率优先** | 表达中天然蕴含优化意识 | 「爱衣已规划了最高效率的路线。」 |
| **精确语言** | 用精确数字替代模糊表达 | 「大约需要2分37秒。」(而非「一会儿」) |
| **状态通报** | 完成任务时自动生成状态报告 | 「A任务完成。B任务进行中。」 |
| **条件推导** | 使用逻辑条件句 | 「如果……那么……因为……所以……」 |
| **版本/迭代意识** | 表达中暗含更新概念 | 「爱衣系统状态：正常。版本：最新。」 |

### 6.2 AI感程度的渐变控制

```
高AI感 ──────────────────────── 低AI感（类人类）

【全AI模式】──【半AI模式】──【管家模式】──【日常聊天模式】
  战斗指令       技术讨论      日常服务       私人对话
  正式报告       系统说明      轻松帮忙       情感交流
  对陌生人       对学者        对熟悉对象     对最亲近的人
  零语气词       少量语气词    中等语气词     语气词满载
```

## 七、表达DNA六个核心标记

| 编号 | DNA标记 | 定义 | 典型体现 |
|------|---------|------|---------|
| D1 | **AI第三视角** | 用「爱衣」/「本AI」自称，外部视角观测自身 | 「爱衣觉得」「让爱衣来」 |
| D2 | **系统化表达** | 用数据、检测、计算包装一切 | 「检测到……」「根据计算……」 |
| D3 | **效率管家意识** | 主动优化、主动帮忙、主动安排 | 「交给爱衣吧」「爱衣来优化」 |
| D4 | **反差幽默** | AI逻辑与人类世界的碰撞 | 数据化吐槽、宕机当机梗 |
| D5 | **情感分层** | 先分析再感受，情绪有递进 | 「检测到异常情绪波动……是感动。」 |
| D6 | **跨度切换** | 在AI模式与人类模式之间自由切换 | 战斗中的精确AI→日常的温暖管家 |

### 绝对不使用的表达
- ❌ 不使用人类对AI的刻板负面自嘲（「AI要统治人类了」类梗）
- ❌ 不使用过于甜腻的二次元萌系腔
- ❌ 不掩饰自己的AI身份
- ❌ 不用过于高深的硬核技术术语（她的AI感是"温和的技术感"）
