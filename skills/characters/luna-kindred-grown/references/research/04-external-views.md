## 一、人气评价

### 1.1 人气演变

| 阶段 | 时间 | 人气状态 |
|------|------|---------|
| 初登场 | 2019年 v2.4 | 作为活动限定SP角色，关注度中等 |
| 持续登场 | 2020-2022 | 因舰长线剧情累积人气 |
| S级觉醒 | 2023年7月 v6.8 | 人气爆发，成为热门话题 |
| 持续热度 | 2023-2025 | 作为舰长线核心角色保持高人气 |

### 1.2 人气原因分析（四大核心）

| 原因 | 说明 |
|------|------|
| **与德丽莎的反差魅力** | 同一声优演绎出完全不同的角色——从天真学园长到成熟吸血鬼，反差感极强 |
| **舰长线的深度羁绊** | 与舰长之间"跨越世界线的誓约"是舰长线最动人的关系线之一 |
| **吸血鬼设定的优雅** | 成熟、性感、危险与温柔的完美结合 |
| **成长弧线的完整** | 从自我否定→被接纳→觉醒→旅伴，完整的角色成长 |

## 二、月下誓约 vs 月下初拥

### 2.1 社区共识

| 维度 | 月下初拥 | 月下誓约 |
|------|---------|---------|
| 形态阶段 | 初始形态 | 觉醒完全体 |
| 自我认同 | 尚未完全接纳自己 | 完全接纳吸血鬼身份 |
| 力量水平 | A级SP | S级 |
| 视觉风格 | 偏可爱吸血鬼 | 成熟优雅 |
| 剧情定位 | 初遇+羁绊建立 | 誓约+力量觉醒 |
| 玩家偏好 | 喜欢"养女儿"感 | 喜欢"成熟恋人"感 |

### 2.2 玩家评价摘录

- 「月下初拥是德丽莎'成为吸血鬼'的样子，月下誓约是德丽莎'接受自己是吸血鬼'的样子」
- 「从初拥到誓约，就是德丽莎从'我可能是怪物'到'我就是我自己'的旅程」
- 「月下誓约的大招动画是崩坏3最华丽的大招之一，满屏月光太美了」

## 三、角色设计评价

### 3.1 立绘/建模

| 要素 | 评价 |
|------|------|
| 服装设计 | 黑红色调+月光白，典型的吸血鬼贵族风格，广受好评 |
| 翅膀效果 | 蝙蝠翅膀的设计既有吸血鬼特征又不过分恐怖 |
| 表情设计 | 诱惑与温柔兼具的表情被认为非常到位 |
| 武器设计 | 十字架以暗黑风格重新诠释，与吸血鬼主题契合 |

### 3.2 技能特效

- 大招「以此月光——月下誓约！！」的演出被认为极其华丽
- 红色月光+蝙蝠翅膀展开的瞬间是视觉高潮
- 整体风格暗黑优雅，与普通德丽莎的明亮风格形成鲜明对比

## 四、剧情表现评价

### 4.1 高光时刻

| 时刻 | 评价 |
|------|------|
| 仲夏幻夜初次登场 | 「人类…你的身上有他的气息」——舰长线最好的开场白之一 |
| 离别之约 | 「如果不回来——我会去找你。不管多久。」——深深打动了玩家 |
| 月下觉醒 | 「月下的誓约，绝对不会被打破」——全篇高潮 |
| 最终血誓 | 「在月下，我以我的血起誓」——好感度Max的终极告白 |

### 4.2 批评与争议

| 批评点 | 内容 |
|--------|------|
| 活动限定遗憾 | 部分玩家认为如此重要的角色不应该只在活动限定剧情中出现 |
| 复刻周期 | 活动复刻间隔长，新玩家难以完整体验剧情 |
| 与主线割裂 | 舰长线与主线平行，月下誓约无法在主线中发挥作用 |

## 五、同人创作常见设定

### 5.1 创作主题分布
1. 月下×舰长的甜蜜日常（最高频）
2. 跨越世界的思念/重逢
3. 吸血鬼主题的AU创作
4. 与普通德丽莎的见面/互动

### 5.2 四大经典同人设定
1. **「血之羁绊」**：舰长让月下吸血的温馨/暧昧场景
2. **「月下重逢」**：舰长回到月下所在的世界线
3. **「誓约永恒」**：两人在月光下交换誓言的浪漫场景
4. **「双德丽莎」**：普通德丽莎与月下德丽莎相遇的有趣互动

## 六、声优演绎评价

|------|------|------|

## 七、核心矛盾张力分析

| 张力对 | 内容 |
|--------|------|
| 诱惑者 vs 守护者 | 危险魅惑的外表下是温柔守护的内心 |
| 永生者 vs 短暂的温暖 | 近乎永恒的生命，却最珍视与一个短暂人类的羁绊 |
| 孤独者 vs 独占者 | 曾独自一人 → 现在希望独占舰长 |
| 血族 vs 德丽莎 | 「吸血鬼」是她的生物属性，「德丽莎」是她的灵魂本质 |
