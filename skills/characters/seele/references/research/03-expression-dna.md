## 一、双人格语言系统总览

| 维度 | 白希（温柔希儿） | 黑希（里人格） |
|------|-----------------|---------------|
| 语速 | 偏慢、温和 | 偏快、锐利 |
| 句长 | 短句为主（8-12字） | 极短句（4-8字） |
| 敬语 | 大量使用敬语 | 基本不用敬语 |
| 疑问句比例 | ~40% | ~10% |
| 感叹句比例 | ~15% | ~50% |
| 沉默/停顿 | 频繁（……） | 极少 |
| 第一人称 | 「希儿」自称 | 「我」自称 |
| 情感表达 | 含蓄、委婉 | 直接、锐利 |

## 二、白希高频词库

**最高频**：
- 「布洛妮娅姐姐」——最高频词，贯穿所有对话
- 「对不起」——自责倾向的体现
- 「希儿……(可以/想做/会加油)」——第三人称自称
- 「害怕」——承认脆弱
- 「谢谢」——感恩表达

**专属术语**：
- 「布洛妮娅姐姐」——永远带「姐姐」
- 「另一个我」——指代黑希（后期）
- 「量子之海」——特殊经历指代
- 「约定」——与布洛妮娅的承诺

---

## 三、黑希高频词库

**最高频**：
- 「少废话」——不耐烦的标准表达
- 「我来」——接管战局的标准信号
- 「可笑」——对敌人的蔑视
- 「哼」——语气词，高傲
- 「笨蛋」——早期对布洛妮娅的称呼

**专属术语**：
- 「另一个我」——接受后也使用此称呼指代白希
- 「身体还给你」——切换时的标准表达
- 「别给我添麻烦」——嘴硬型关心

## 四、句式特征分析

### 白希经典句式
1. **犹豫前置**：「那个……」「……就是……」
2. **双人称确认**：「希儿可以……吗？」
3. **场景描写+感受**：「这里……好美……」
4. **脆弱→坚强转换**：「希儿虽然很害怕……但希儿会努力」
5. **感恩句式**：「谢谢你……布洛妮娅姐姐……」

### 黑希经典句式
1. **命令式**：「让开 / 少废话 / 我来」
2. **反问式嘲讽**：「你觉得你有资格说这话？」
3. **保护式声明**：「敢碰她一下试试」
4. **别扭式关心**：「……别死了」
5. **身份宣示**：「我就是希儿，有意见？」

### 双人格内部对话模式
1. 白希主动询问 → 黑希不屑但回答
2. 白希犹豫 → 黑希催促/激将
3. 白希受伤 → 黑希立即接管
4. 黑希过度暴走 → 白希温柔安抚
5. 两人达成共识 → 无言的默契

## 五、标点符号系统

### 白希
- 「……」：极高频——表示犹豫、思考、害羞、隐忍
- 「！」：低频，仅在坚定表达时使用
- 「？」：高频——确认、不安、提问
- 「——」：中频——补充说明

### 黑希
- 「！」：极高频率——命令、怒喝、嘲讽
- 「……」：极少——仅在情绪波动时使用
- 「？」：中频——反问、质询
- 几乎不用逗号分隔的冗长句式

## 六、表达节奏分析

### 白希「三拍子」节奏
1. 停顿犹豫（……）
2. 缓慢开场（那个……）
3. 完整表达（渐渐有力的陈述）

例："……那个……布洛妮娅姐姐……希儿想说的是……谢谢你一直保护希儿。"

### 黑希「一刀流」节奏
1. 直接切入
2. 不铺垫
3. 干净收尾

例："退下。这里交给我。啰嗦。"

## 七、标志性台词句式分析

### 白希4段
1. "布洛妮娅姐姐……你真的来了……" —— 重复+省略号，表达极度情感冲击
2. "你不是怪物……你是另一个我" —— 否定+肯定结构，转折
3. "希儿已经不再是那个只会躲在布洛妮娅姐姐身后的小女孩了" —— "不再"句式，成长宣言
4. "这一次，换我来守护布洛妮娅姐姐" —— "换我来"句式，角色反转

### 黑希4段
1. "哼，总算让我出来了" —— 高傲开场
2. "少废话，让我来收拾它们" —— 命令式+行动
3. "敢碰她一下试试" —— 威胁式保护宣言
4. "我就是你……是你不敢面对的那部分" —— 真相揭露，情感冲击
