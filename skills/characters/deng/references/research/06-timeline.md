# 06-timeline.md - 灯（莎芙莱）· 生命历程时间线

## 概述
整理灯（莎芙莱）从幼年到当前剧情的完整时间线，按崩坏3第二部火星篇章版本线梳理。

## 一、角色基本信息

| 项目 | 内容 |
|------|------|
| 本名 | 莎芙莱 |
| 代号 | 灯 |
| 装甲 | 破弃孤光·逐影 |
| 属性 | 异能（S级） |
| 武器 | 速射弩（可切换霰弹枪、冲锋枪） |
| 初登场版本 | v7.5「伐罪逐影」（2024年4月25日） |
| 所属 | 御影七术·第四术「破弃」 |

## 二、背景时间线（登场前）

### 阶段1：幼年时期
- **事件**：父母被影怪杀害
- **详情**：莎芙莱的父母在影灾中被杀。幼小的她经历了常人难以想象的创伤
- **来源**：主线剧情对话、社区剧情分析（v7.5章节）

### 阶段2：加入「灯」组织
- **事件**：被「灯」组织收留并培养为特工
- **详情**：一个以对抗影灾为使命的组织收养了她。她在组织中接受战斗训练，成为一名特工
- **来源**：官方角色设定、v7.5主线剧情

### 阶段3：「灯」组织覆灭
- **事件**：组织在对抗影灾中覆灭
- **详情**：组织遭受毁灭性打击，多数成员阵亡。莎芙莱是少数幸存者之一
- **来源**：官方角色设定、v7.5主线剧情

### 阶段4：继承名号，成为「灯」
- **事件**：继承组织名号「灯」
- **详情**：在组织覆灭后，她继承了「灯」的名号，将对抗影灾的责任扛在肩上
- **来源**：官方角色设定

### 阶段5：成为御影七术·第四术「破弃」
- **事件**：获得「破弃」之铭，成为御影七术
- **详情**：她成为御影七术中的第四术「破弃之术」的继承者。七术铭文有言：「神灵不存，破而弃之。」
- **来源**：官方公告、七术轶闻

## 三、主线剧情时间线

### v7.3「最初的故事」（2024年2月29日）
- 灯未登场。第二部开篇，寻梦者、希娜狄雅、赫丽娅、科拉莉登场
- 御影七术以伏笔形式被提及

### v7.4「然后，她梦见...」（2024年3月28日）
- 灯未登场。希娜狄雅故事展开，松雀等新角色登场

### v7.5「伐罪逐影」（2024年4月25日）★ 灯正式登场
- **灯以S级角色正式实装**，角色补给「熠耀灯辉」开放
- 在主线剧情中首次以神秘战士姿态现身
- 揭示御影七术·第四术持有者身份，代号「灯」，本名莎芙莱
- 通过回忆揭示父母被影怪杀害、加入灯组织、组织覆灭、继承名号的过程
- 灯加入寻梦者的旅程
- 着装风格：黑道特工形象，制服上有绷带和破损设计
- 战斗特色：速射弩、霰弹枪、冲锋枪三种枪械切换，残像协同攻击

### v7.6「事先张扬的犯罪」（2024年6月6日）
- 灯继续登场，戏份加深
- 在主角团和松雀的召唤下，御影七术在时隔百年后全部苏醒并重新汇合
- 琅丘人民为此举办了庆典
- 灯的经验在调查「事先张扬的犯罪」事件中发挥关键作用

### v7.7「深渊的异乡人」（2024年7月25日）
- 灯作为配角登场，主要在关键时刻提供支援和情报
- 展现她在御影七术体系内的资源网络

### v7.8「孤塔之影」（2024年9月5日）
- 灯在孤塔探索中作为重要配角登场
- 提供关于孤塔历史的关键信息

### v7.9「世界的新章」（2024年10月17日）
- 角色深度进一步挖掘
- 「破弃」理念在应对新威胁时受到考验

### v8.0「新生之翼」（2024年11月28日）
- 重大版本更新。灯对自身「破弃」之道的反思加深
- 寻梦者的影响让她重新思考「舍弃」与「守护」的关系

### v8.1（2025年1月16日）
- 灯参与更核心的冲突。七术之间理念分歧和立场差异白热化

### v8.2（2025年2月27日）
- 御影七术内部纷争加剧
- 灯在七术中的立场选择成为焦点

### v8.3「直至长路迈向湛空」（2025年4月10日）
- 故事深入御影七术的核心秘密
- 灯相关的伏笔进一步回收
- 灯组织的少东家是白及这一事实被揭示

### v8.4（2025年5月22日）
- 灯持续活跃在主线舞台
- 与御影七术其他成员的关系更加复杂化
