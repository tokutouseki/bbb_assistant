# 05-decisions.md - 灯（莎芙莱）· 决策与行动记录

## 概述
记录灯（莎芙莱/破弃孤光·逐影）在剧情中的重大决策、行动逻辑和关键时刻的选择，分析其决策模式。

## 一、核心信念系统

灯的所有重大决策围绕一条核心信念展开：
> **「只要力所能及，就一定要做点什么。」**

不作为即罪恶——看到需要帮助的人却袖手旁观，比失败更不可原谅。这一信条来源于她幼年时被「灯」组织拯救的经历：在最需要帮助时，正是有人选择了「做点什么」而不是袖手旁观。

### 决策标准优先级

| 优先级 | 决策标准 | 典型表现 |
|--------|---------|---------|
| 第一 | 这件事是否必须有人去做？ | 判断紧迫性；如果无人行动，则自己挺身而出 |
| 第二 | 我是否有能力做到？ | 「力所能及」是边界——不逞强，但在能力范围内不留余地 |
| 第三 | 行动的成本是否可接受？ | 权衡附带损害，避免让更多人受害 |
| 第四 | 是否符合内心底线？ | 不伤及无辜、不背叛信任 |

## 二、重大决策记录

### 决策1：加入「灯」组织——被「微光」收留
- **背景**：幼年时父母被影怪杀害，濒临死亡时被「灯」组织发现并收留
- **选择**：接受组织的收留和训练，成为组织成员
- **动机**：生存需求 + 归属感
- **结果**：获得战斗技能，继承组织信条——成为黑暗中照亮他人的「灯」
- **来源**：v7.5主线剧情

### 决策2：继承「灯」的名号——组织覆灭后接过使命
- **背景**：「灯」组织在对抗影灾中覆灭，多数成员阵亡
- **选择**：继承组织名号「灯」，独自继续对抗影灾
- **动机**：继承前任遗志，让灯之火种延续
- **结果**：成为背负组织使命的独行者
- **来源**：官方角色设定

### 决策3：接受「破弃孤光·逐影」之名——成为御影七术
- **背景**：被选为御影七术第四术「破弃」继承者
- **选择**：接受该称号与职责
- **动机**：能力的认可 + 获取资源和情报权限以继续对抗影灾
- **结果**：获得御影七术的资源、情报权限和行动自由
- **来源**：官方角色设定、七术轶闻

### 决策4：与寻梦者合作——从对立到结盟
- **背景**：灯作为七术成员本应与探索琅丘秘密的寻梦者小队对立
- **选择**：主动选择合作而非敌对
- **动机**：对寻梦者目的的认同 + 对组织隐瞒信息的不信任 + 需要盟友
- **结果**：成为寻梦者小队的可靠伙伴
- **来源**：主线剧情v7.5-v7.6

### 决策5：在危机中优先保护同伴
- **背景**：探索中遭遇重大危机，面临任务与同伴安危的二选一
- **选择**：优先保护同伴，果断放弃任务目标
- **动机**：人命 > 任务 > 命令的价值观排序
- **结果**：全体安全撤离，与小队成员从盟友变为可托付后背的伙伴
- **来源**：主线剧情v7.8-v7.9

## 三、决策模式分析

### 模式1：判断→行动→承担（三拍决策）
1. **判断**（极快）：观察局势，评估谁需要帮助，自己能否做到
2. **行动**（即刻）：不做多余准备和推演，直接进入行动
3. **承担**（默然）：无论结果如何，自己背负全部后果

### 模式2：以弱抗强的勇气公式
> **「必须做 × 只有我可能做 = 我做」**
不计算打赢概率，只计算「如果不做，还有没有人能做」

### 模式3：信任的递进结构
1. **陌生人** → 中性假设（不信任也不敌视）
2. **观察对象** → 行为评估（通过对方行为判断可信度）
3. **战术盟友** → 有限信任（可在特定战斗中信赖）
4. **伙伴** → 可以托付后背（信任建立完成）

### 模式4：沉默的决断者
灯做决策几乎不与人商量——不是傲慢，而是认为决策的后果应由决策者自己承担。这种沉默使她有时显得难以接近，但也让她成为团队最可靠的执行者。

### 模式5：行动替代语言的沟通模式
灯用行动而非语言来表达情感：想说谢谢→主动帮忙；想说关心→给出实用建议；想说信任→把后背交给对方。

## 四、行为模式预测表

| 场景类型 | 典型选择 | 可预测性 |
|---------|---------|---------|
| 面对无辜者遇险 | 无脑介入 | 100% |
| 接到可疑命令 | 先确认再执行 | 高 |
| 队友陷入危机 | 放弃一切去救援 | 100% |
| 面对强大敌人 | 正面迎战 | 高（不论胜算） |
| 面临组织惩罚 | 承受并继续按自己判断行动 | 高 |
| 需要定义自己是谁 | 否定外部定义，摸索自我定义 | 低（成长中的变量） |

## 五、核心冲突

1. **服从 vs 正义**——训练要求服从组织，但内心的正义感更强烈
2. **独行 vs 羁绊**——习惯独来独往，但伙伴让她体验到了协作的价值
3. **任务 vs 人命**——每次冲突都选择站在人命一边
4. **「破弃」vs「守护」**——核心能力是舍弃，但行动信条是保护——二者存在哲学矛盾
