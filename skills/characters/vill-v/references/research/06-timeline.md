# Agent 6: 时间线 — 维尔薇（Vill-V / 螺旋之铭）

> 调研基于崩坏3主线剧情、往世乐土剧情、角色装甲故事、神之键档案、游戏内记忆片段等一手来源。
> 调研时间：2026年5月26日

---

## 一、前文明纪元完整时间线（约五万年前）

### 阶段一：出生与早年生涯

| 相对时序 | 事件 | 说明 |
|---------|------|------|
| 前文明科技全盛期 | 维尔薇出生于前文明 | 具体背景未详细披露 |
| 少年时代 | 展现超越常人的机械与工程学天赋 | 被誉为前文明最杰出的天才发明家 |
| 青年时代 | 独立完成多项重大发明 | 以"一个人就是一支研发团队"著称 |

### 阶段二：加入逐火之蛾

| 相对时序 | 事件 | 说明 |
|---------|------|------|
| 崩坏战争早期~中期 | 被逐火之蛾招募为武器研发专家 | 因超凡发明能力被征召 |
| 加入初期 | 设计制造大量先进武器装备 | 大幅提升对抗崩坏的科技水平 |
| 早期~中期 | 人格分裂·萌芽期 | 巨大工作压力和道德困境催生最初的无意识分裂 |

### 阶段三：人格分裂的发展历程

| 人格 | 出现时序 | 职能/特点 |
|------|---------|----------|
| **本体·发明家** | 最初人格（原始） | 对外社交、展示、表演的核心人格 |
| **专家** | 第一分裂（早期） | 冷血高效，负责战斗和危险任务 |
| **技师** | 第二分裂（中期） | 务实耐心，负责实际建造和维护 |
| **螺旋** | 原初自我（被埋藏） | 真正的维尔薇，被所有人格遗忘 |

**人格分裂的本质**：不是精神疾病，而是维尔薇的**主动设计**。核心动机——"作为一个人无法承受所有事，所以我把不同的职责分给了不同的我"。

### 阶段四：成为逐火十三英桀第五席·螺旋之铭

| 事件 | 说明 |
|------|------|
| 融合战士手术 | 以"螺旋"（Helix）为融合基因获得特殊能力 |
| 英桀评定 | 被授予**第五席**，获**「螺旋」之铭**（Signet of Helix） |

**刻印含义**：如螺旋般不断旋转、进化、突破的创新精神。

### 阶段五：重要发明时间点

| 相对时序 | 发明/项目 | 说明 |
|---------|----------|------|
| 加入初期 | 各类常规武器装备 | 基础枪械、装甲、崩坏能武器 |
| 中期 | 螺旋因子系统 | 实现人格可控切换的技术基础 |
| 中期 | 螺旋兵器系统 | 螺旋能量为核心的战斗系统 |
| 中期~后期 | **神之键系统总设计** | 主导设计将律者核心转化为人类武器的框架 |
| 后期 | 第十一神之键·吞噬之键 | 以侵蚀之律者核心为基础制造 |
| 后期 | **往世乐土核心架构** | 英桀记忆虚拟空间的技术设计 |
| 终末 | **"最后的保险"** | 内容未披露的最终手段 |

> 神之键系统并非维尔薇一人完成——她是**总设计师/架构师**，多位英桀参与制造。

### 阶段六：关键战役参与

| 战役 | 角色 |
|------|------|
| 第1~9律者讨伐战 | 武器研发与技术支援 |
| **第11律者·约束之律者战** | **幸存者之一**——最惨烈战役 |
| 第12律者·侵蚀之律者战 | 核心人物——制造吞噬之键 |
| 终焉之战 | 后方·技术保存 |

### 阶段七：与凯文的交易（核心谜团）

| 要素 | 内容 |
|------|------|
| 交易方 | 维尔薇 × 凯文 |
| 时间 | 往世乐土建成前后，终焉之战前夕 |
| 已知内容 | 维尔薇**自愿进入往世乐土**并同意将自己"困"在其中 |
| **未解之谜** | 交易完整条款从未披露 |

> *"我和凯文做了一笔交易。作为代价，我把自己关在了这里。"*
> *"但交易的内容——我建议你不要问得太深。"*

### 阶段八：往世乐土中的活动

| 事件 | 活动 |
|----------|------|
| 乐土建立 | 以第五英桀记忆体入驻，完整五人格存在 |
| 长期维持 | 运营**「螺旋剧场」** |
| 雷电芽衣进入 | 以多人格表演形式接待芽衣 |
| 试炼过程 | 考验芽衣关于"真实"与"自我"的本质 |
| 真相碎片 | 透露部分与凯文的交易内容 |
| 乐土篇章完结 | 完成引导使命，作为常驻玩法保留 |
