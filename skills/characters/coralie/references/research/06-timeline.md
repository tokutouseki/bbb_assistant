## 二、完整剧情时间线

### v7.3 ——「最初的故事」（首次登场）

| 事件 | 详情 |
|------|------|
| 首次登场 | 与赫丽娅作为火星探索小队成员登场 |
| 初遇寻梦者 | 在火星柯洛斯滕学院与寻梦者相遇 |
| 首次战斗 | 遭遇影怪袭击，展现远程火力战斗风格 |
| 小队成立 | 与赫丽娅、寻梦者组成三人小队 |

### v7.4 ~ v7.5 ——「星火初燃」

| 事件 | 详情 |
|------|------|
| 深入遗迹 | 探索火星古代文明遗迹 |
| 首次受挫 | 面对强敌时暴露出经验和实力的不足 |
| 星铠适配 | 接受星铠系统的适配与同步 |
| 性格深化 | 表面乐天派下隐藏的对「真相」的执着 |

### v7.6 ——「数据之海探索」

| 事件 | 详情 |
|------|------|
| 初入数据之海 | 探索火星深层系统「数据之海」 |
| 初遇希娜狄雅 | 在数据之海中首次遇到希娜狄雅 |
| 战斗升级 | 面对更强形态的影怪 |

### v7.7 ~ v7.8 ——「七术浮出水面」

| 事件 | 详情 |
|------|------|
| 七术初现 | 接触火星文明守护者「七术」的线索 |
| 首次与七术交锋 | 与七术中的某位进行战斗，惨败 |
| 挫败感显现 | 暴露出不自信的一面——平日用元气掩盖的不安 |
| 理念分歧 | 与赫丽娅在面对七术的态度上开始出现微妙分歧 |

### v7.9 ——「诡戏·千役」觉醒

| 事件 | 详情 |
|------|------|
| 新装甲实装 | 「诡戏·千役」（Trickster / Thousand Duties）正式实装 |
| 能力突破 | 在七术试炼中突破自身极限，觉醒新战斗形态 |
| 角色深化 | 装甲主题揭示科拉莉隐藏的复杂内心 |

### v8.0 ~ v8.1 ——「七术正面冲突」

| 事件 | 详情 |
|------|------|
| 七术正式登场 | 灯（破弃之术）、松雀（欺瞒之术）等正式出场 |
| 正面冲突 | 科拉莉与七术发生正面冲突，再次惨败 |
| 关系裂痕 | 与赫丽娅因对七术态度差异关系紧张 |

### v8.2 ——「琅丘篇章」

| 事件 | 详情 |
|------|------|
| 抵达琅丘 | 故事转移到火星城市琅丘 |
| 战术指挥首秀 | 在琅丘地下设施防卫战中首次担任战术指挥 |
| 心态成熟 | 从「莽撞冲锋」向「有策略的出击」转变 |

### v8.3 ~ v8.4 ——「深空余响」

| 事件 | 详情 |
|------|------|
| 真相揭晓 | 火星系统的真正面目开始浮出水面 |
| 信念危机 | 得知真相后面临「战斗的意义是什么」的拷问 |
| 与赫丽娅和解 | 大吵之后二人更加理解彼此，关系走向成熟 |
| **牺牲** | 在十术战争中为赫丽娅挡下利托斯特致命一击 |

### v8.5 ~ v8.6 ——「终幕前奏」

| 事件 | 详情 |
|------|------|
| **归来** | 赫丽娅三次献祭后，科拉莉以某种方式归来 |
| 新力量觉醒 | 归来的科拉莉展现出新的力量层次 |
| 七术系统危机 | 系统中出现「叛变」或「失控」的迹象 |
| 最终章序幕 | 故事正在走向第二部最终章的高潮 |
