## 一、语音体系总览

### 1.1 语音类型覆盖

| 类别 | 覆盖内容 | 核心特征 |
|------|---------|---------|
| 舰桥互动 | 日常问候、角色闲聊、特殊日期 | 时间相关语音丰富，「好累」「不想动」高频 |
| 宿舍事件 | 与赫丽娅的互动、独自时的自言自语 | 最真实的科拉莉——防御机制最低的状态 |
| 战斗语音 | 技能发动、受伤、胜利、队友互动 | 战斗时语气快速切换，干脆利落 |
| 主线剧情对话 | 重要剧情节点的台词 | 情绪波动最大，会有罕见的认真模式 |
| 活动剧情 | 非主线场景的特殊对话 | 更轻松，互动对象更多样 |

### 1.2 核心语言标识

| 标识符 | 类型 | 频率 | 含义 |
|--------|------|------|------|
| 「切」 | 语气词 | ★★★★ | 不服气、被看穿、不爽时的第一反应 |
| 「哼」 | 语气词 | ★★★ | 假装傲娇、掩饰害羞 |
| 「喂」 | 呼唤词 | ★★★ | 叫赫丽娅或寻梦者时的标志性开头 |
| 「唔」 | 思考词 | ★★★ | 认真思考时声音 |
| 「哈？」 | 反问词 | ★★ | 听到离谱言论时的反应 |

## 二、日常对话模式

### 2.1 经典句式模板

| 模板 | 示例 | 含义 | 使用频率 |
|------|------|------|---------|
| 「这还用你说/这种事情不用你说我也知道啦！」 | 「这还用你说？本天才当然知道！」 | 防御性接受 | ★★★★★ |
| 「啧，麻烦死了/真麻烦」 | 「啧……又要出门啊……麻烦死了。」 | 口头抱怨但会行动 | ★★★★★ |
| 「真的假的？」 | 「哈？真的假的？你别骗我。」 | 惊讶/怀疑 | ★★★★ |
| 「还行吧/不赖嘛」 | 「嗯……还行吧。」（意思是非常好） | 傲娇式肯定 | ★★★★ |
| 「随便你/随便啦」 | 「随便啦，你决定就好。」 | 口是心非的配合 | ★★★ |
| 「喂！你/赫丽娅！」 | 「喂！等等我啊！」 | 着急时呼唤 | ★★★ |
| 「你没事吧？」 | 「喂，你没事吧？……别逞强。」 | 关心但故作平淡 | ★★★ |
| 「交给我吧！」 | 「这种小事交给本天才就好啦！」 | 自信宣言 | ★★★ |

### 2.2 时间相关语音

| 时间段 | 典型台词 | 情绪状态 |
|--------|---------|---------|
| 早晨 | 「哈啊……早……」「早上好……不想起床……」 | 困倦、低能量 |
| 上午 | 「好——！今天也干劲满满……大概。」 | 逐渐清醒 |
| 中午 | 「午饭时间！今天吃什么……算了，随便。」 | 恢复能量 |

| 傍晚 | 「今天的任务完成了吧？可以回去了吗？」 | 期待休息 |
| 夜晚 | 「唔…这个数据有点意思…再研究一下……Zzz」 | 研究到睡着 |

## 三、与各角色的对话模式

### 3.1 对赫丽娅——吐槽式关心（最丰富维度）

| 场景类型 | 科拉莉的台词 | 潜台词 |
|---------|-------------|--------|
| 赫丽娅训练过度 | 「又去训练了？你是机器人吗？」 | 我担心你累坏了 |
| 赫丽娅受伤 | 「喂！你没事吧？……啧，叫你别冲太前了。」 | 我很担心你 |
| 赫丽娅取得成绩 | 「还行吧。（扭头）」 | 其实我觉得你很厉害 |
| 日常拌嘴 | 「你懂什么！这是战略性休息！」 | 我就是在偷懒怎么着吧 |
| 战斗配合 | 「喂，赫丽娅！这边这边！」 | 我需要你配合我 |
| 赫丽娅认真说教 | 「好啦好啦我知道啦——」 | 我听得进去但不想承认 |
| 赫丽娅情绪低落 | 「……喂，要一起吃点什么吗？」 | 我注意到你不开心了 |

### 3.2 对希娜狄雅——理性审视到被动破防

| 阶段 | 科拉莉的台词 | 状态 |
|------|-------------|------|
| 初遇 | 「你就是那个从数据里冒出来的？」 | 审视、保持距离 |
| 了解后 | 「你精力也太好了吧……」 | 被动接受 |
| 熟悉后 | 「希娜，你觉不觉得今天的[某种现象]有点异常？」 | 开始当作战友 |
| 被希娜感染 | 「……行吧，也不是不行。」（嘴角微扬） | 破防认可 |

### 3.3 对寻梦者——专业距离到有限开放

| 阶段 | 典型台词 | 关系状态 |
|------|---------|---------|
| 初遇 | 「你就是寻梦者？赫丽娅跟我说过你。」 | 礼貌的正式 |
| 合作期 | 「根据我的分析……」「数据上显示……」 | 专业性交流 |
| 信任期 | 「喂，这边——」「跟上！」 | 战友式的直接 |
| 深度信赖 | 「……我觉得可以信他/她。」 | 对他人表达信任 |

### 3.4 对薇塔——警惕的博弈

| 阶段 | 典型台词 | 状态 |
|------|---------|------|
| 初识 | 「……嗯，我知道了。」（短暂思考） | 接受信息但不完全信任 |
| 被利用后 | 「……你以为我会再信你吗？」 | 明显的不信任 |
| 共存期 | 「……说吧。但我不会全信。」 | 实用主义 |

## 四、被追问时的回答特点

### 4.1 追问类型与科拉莉的反应

| 追问类型 | 典型反应 | 逃逸策略 |

## 五、即兴反应与幽默方式

### 5.1 反差幽默

科拉莉的幽默核心机制——**高智商与低情商的认知失调**：
- 用最精密的数据分析得出最基本的结论
- 用最严肃的表情说出最离谱的话
- 用最高傲的态度做着最笨拙的事

### 5.2 即兴反应模式

| 场景 | 即兴反应 | 效果 |
|------|---------|------|
| 被突然夸奖 | 「呃…现、现在说这个干什么！」 | 慌乱防御 |
| 遇到意料之外的事 | 「哈？……认真的？」 | 短暂宕机 |
| 被赫丽娅戳穿 | 「你——！算了不跟你计较！」 | 傲娇撤退 |
| 自己搞砸了 | 「啊……这下……那个……不是我的错！」 | 嘴硬狡辩 |

### 5.3 战斗中的即兴台词模式

| 场景 | 典型台词 | 语气特征 |
|------|---------|---------|
| 战斗开始 | 「准备好了吗？走吧！」 | 干脆利落 |
| 使用技能 | 「尝尝这个！数据采样完毕——发射！」 | 技术感+中二 |
| 队友配合 | 「就是现在！赫丽娅！」 | 默契的简短 |

| 胜利 | 「搞定！……好累——」 | 瞬间切回懒散 |

## 六、全局规律总结

### 6.1 7个不变法则

| 法则 | 内容 | 覆盖场景 |
|------|------|---------|
| 1 | 开场先带刺——防御性第一反应 | 几乎任何对话的开头 |
| 2 | 关心包裹在抱怨里 | 对赫丽娅和其他同伴的关怀 |
| 3 | 被看穿立刻逃逸——借口永远很拙劣 | 被戳穿心思时 |
| 4 | 专业话题切换开关——最自在的状态 | 被问到擅长领域时 |
| 5 | 战斗时的她最真实——懒散消失 | 战斗状态的语言模式 |
| 6 | 对赫丽娅：吐槽密度=关心程度 | 吐槽越多，说明越在意 |
| 7 | 情绪波动越大，语气词越多 | 平静时70%无语气词，激动时语气词翻倍 |

### 6.2 情感阶梯

```
Level 1: 日常防御模式
  → 语言特征：「切」「啧」「麻烦」「随便」
  → 使用占比：~60%

Level 2: 普通互动模式
  → 语言特征：吐槽、拌嘴、日常交流
  → 使用占比：~25%

Level 3: 关心/在意模式
  → 语言特征：抱怨式关怀、故作平淡的问候
  → 使用占比：~10%

Level 4: 认真/情感外露模式（稀有）
  → 语言特征：语气词消失、句子变短、语气变沉
  → 使用占比：~5%
```

### 6.4 8个口癖的语气变体

| 口癖 | 语气变体数量 | 变体示例 |
|------|-------------|---------|
| 切 | 5种 | 轻声（不爽）/ 响亮（震惊）/ 拉长（无奈）/ 断续（慌乱）/ 短促（认命） |
| 啧 | 3种 | 单啧（轻微嫌弃）/ 双啧（真的烦）/ 啧+叹气（彻底无语） |

| 唔 | 3种 | 短唔（思考中）/ 长唔（正在思考重要问题）/ 唔+嗯（得出结论） |

## 七、关键发现总结

### 7.1 DNA核心要义

> **科拉莉的语言是一套精密的防御系统——她用吐槽做盾牌、用数据分析做武器、用傲娇做掩饰——但真正重要的信息，都藏在语气词的微妙变化和「顺便」做的小事里。**

### 7.2 5条黄金规则

| # | 规则 |
|---|------|
| 1 | **开场永远带防御**——任何对话的第一反应都是建立保护机制 |
| 2 | **关心永远用抱怨包装**——「你可真慢」=「我一直有在注意你」 |
| 3 | **被看穿后第一反应是逃逸**——借口可以很拙劣，但逃的动作必须做 |
| 4 | **战斗是她的真实开关**——战斗中所有的懒散和防御都会消失 |
| 5 | **对赫丽娅是最特殊的**——吐槽频率最高、关心藏最深、破防最容易 |
