## 一、核心决策逻辑

科拉莉的所有重大决策围绕一条核心张力展开：

> **「在身为远征队员的责任与保护身边人的本能之间，如何保持前进的勇气？」**

### 决策优先级

| 优先级 | 决策标准 | 典型表现 |
|--------|---------|---------|
| 第一 | 是否保护队友（尤其是赫丽娅） | 主动殿后、以身挡敌 |
| 第二 | 是否完成火星远征任务 | 即使受伤也不放弃任务目标 |
| 第三 | 是否维护自己的尊严和骄傲 | 不服输、坚持战斗到底 |
| 第四 | 是否在战术上做出正确判断 | 逐渐学会在冲动前先思考 |

### 决策1：加入火星远征队（v7.3）

| **对角色的影响** | 正式开启科拉莉在第二部的主线旅程 |

| **动机** | 保护队友的本能 + 对自己战斗力的自信 |

| **对角色的影响** | 暴露了她「过度自信」的倾向——勇气可嘉但缺乏风险评估 |

## 三、战斗风格分析

### 3.1 核心战斗特点

| 特点 | 描述 | 典型表现 |
|------|------|---------|
| **远程火力** | 以重炮远程压制为主 | 「数据采样完毕——发射！」 |
| **数据分析辅助** | 战斗前/中持续分析敌方模式 | 「异常检测报警——目标位置确认。」 |
| **战术支援** | 为队友提供火力掩护和数据支持 | 「赫丽娅，就是现在！」 |
| **共鸣爆发** | 关键时释放星之环力量 | 「核心过载——给我撑住！」 |

### 3.2 战斗风格进化

| 阶段 | 版本区间 | 战斗风格特征 |
|------|---------|-------------|
| 初登火星 | v7.3~v7.5 | 莽撞冲锋、纯力量型、缺乏战术配合 |
| 星铠适配期 | v7.5~v7.8 | 开始学习控制力量、尝试与赫丽娅配合 |
| 战术成熟期 | v8.0~v8.3 | 有了殿后意识和撤退判断、懂得分担压力 |
| 终极觉醒 | v8.4+ | 力量与战术意识兼备、成为可靠的团队核心 |

## 四、解决问题的方式

### 4.1 典型思维模式

科拉莉的解决问题方式可以用「三阶段递进」概括：

1. **直觉反应**：遇到问题第一反应是「用行动解决」
2. **反思修正**：当行动失败或不够充分时，开始思考策略
3. **经验整合**：将过去的教训转化为未来的行动指南

### 4.2 具体场景中的问题解决

| 场景 | 科拉莉的处理方式 | 评估 |
|------|----------------|------|
| 遇到不明威胁 | 先战斗后侦察 | 容易陷入被动，但符合性格 |
| 装备/技术故障 | 工程学知识直接上手维修 | 专业领域，表现最可靠 |
| 团队内部矛盾 | 用行动证明而非言语争辩 | 有效但不够通达 |
| 战略选择困境 | 倾向于信任寻梦者的判断 | 体现深度信赖 |
| 被算计后 | 下次见面时提高警惕但不拒绝合作 | 实用主义 |

## 五、危机反应模式

### 5.1 危机反应金字塔

```
Level 1：轻度威胁
  → 反应：主动迎战、充满自信
  → 「让我来！」

Level 2：中度威胁
  → 反应：评估后决定战斗或撤退
  → 「先试试看，不行再撤。」

Level 3：重度威胁
  → 反应：保护队友优先、自我牺牲倾向
  → 「你们先走，我殿后！」

Level 4：绝望级威胁
  → 反应：爆发出超越极限的力量
  → 「还没结束呢！」
```

### 5.2 危机反应进化

| 阶段 | 早期（v7.3~v7.6） | 中期（v7.7~v8.2） | 后期（v8.3+） |
|------|-------------------|------------------|--------------|
| 第一反应 | 直接冲上去 | 先观察再行动 | 快速评估全局 |
| 风险意识 | 几乎没有 | 开始考虑后果 | 理性权衡 |
| 寻求帮助 | 很少 | 会叫赫丽娅配合 | 主动请求支援 |
| 撤退意愿 | 极低 | 必要时会撤 | 策略性撤退 |

## 六、成长弧线

### 6.1 成长路径

```
冲动的新手 → 受挫的战士 → 反思的学习者 → 可靠的队友 → 独当一面的守护者
```

### 6.2 成长阶段详解

| 阶段 | 版本 | 状态 | 标志事件 |
|------|------|------|---------|
| 初登火星 | v7.3~v7.5 | 自信爆棚、经验不足 | 正面迎战影兽 |
| 星铠考验 | v7.5~v7.7 | 意识到自己不够强 | 接受星铠系统 |
| 三角博弈 | v7.7~v8.0 | 学会分辨敌友 | 看穿薇塔的操纵 |
| 成熟战士 | v8.0~v8.4 | 从「我」到「我们」 | 主动殿后、与赫丽娅深化配合 |
| 终极觉醒 | v8.4+ | 从被保护者变为保护者 | 归来后的新力量 |

### 6.3 核心价值观冲突

| 冲突 | 进化路径 |
|------|---------|
| 冒险精神 vs 风险管理 | 从「不管了，先冲」到「冲之前，先想好退路」 |
| 个人骄傲 vs 团队协作 | 从「我要证明自己最强」到「我们一起才是最强」 |
| 信任本能 vs 审慎判断 | 从「谁都可以信任」到「信任需要验证」 |
| 行动欲望 vs 忍耐克制 | 从「马上行动」到「等待时机也是行动的一部分」 |
| 保护欲 vs 自我保全 | 从「我死了没关系」到「我必须活着才能保护他们」 |
