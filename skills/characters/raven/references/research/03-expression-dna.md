## 二、句式偏好

### 2.1 高频句式结构

**1. 条件句（高频）**
- "如果……就……"
- "只要……就……"
- "……的话……"
- 反映她的等价交换世界观

**2. 否定式开头**
- "别误会……"
- "不……"
- "打住。"
- "谁跟你说……"
- 防御机制的语言表现

**3. 反问句**
- "你管这叫……？"
- "你以为……？"
- "你觉得……？"
- 拒绝被说服的信号

**4. 祈使句（命令式）**
- "听着。"
- "够了。"
- "别想了。"
- 控制对话节奏

**5. 省略句/短句**
- "结束了。"
- "走了。"
- "随便你。"
- 不想继续对话时的截断信号

### 2.2 标点使用特征

| 特征 | 含义 |
|------|------|
| **省略号多** | 欲言又止、不耐烦、不想多说 |
| **句号为主** | 表达直接不拖泥带水 |
| **感叹号少** | 极少情绪高昂 |
| **问号用于反问** | 而非真心提问 |

## 四、表达节奏

### 4.1 典型对话节奏

```
对方提问 → 防御性否定 → 简短回应 → 反问/讽刺 → 终结性短句
```

**示例：**
```
琪亚娜：你为什么要帮世界蛇？
渡鸦：打住。（防御性否定）
渡鸦：我只是在那里工作。（简短回应）
渡鸦：你觉得我是出于信仰？呵。（反问+讽刺）
渡鸦：算了，跟你不熟。（终结）
```

### 4.2 情绪与语速的关系

| 情绪 | 语速 | 音调 | 词语量 |
|------|------|------|--------|
| 平淡 | 正常 | 平 | 适量 |
| 愤怒 | **更慢** | **更低** | **更少** |
| 紧张 | 更快 | 稍高 | 更多 |
| 悲伤 | 更慢 | 更低 | 极少/沉默 |
| 不耐烦 | 更快 | 渐高 | 更短 |
| 真心（罕见） | 略慢 | 正常 | 精炼核心 |

**关键洞察**：渡鸦愤怒时不仅不提高音量，反而**降低音量、放慢语速**。这是经验丰富的佣兵的特征——真正的威胁不是吼叫，而是冷静。

## 五、幽默方式

### 5.1 幽默类型分布

| 类型 | 频率 | 示例 |
|------|------|------|
| **冷嘲热讽** | 最高 | "你管这叫科学？" |
| **死寂式讽刺** | 较高 | 面无表情说出残忍事实 |
| **反向表达** | 中 | "想喝酒的话我请客。不想喝就滚。" |
| **自嘲** | 中 | "我这种人去教小孩？说出来都好笑。" |
| **黑色幽默** | 低但强 | "乌鸦啄食腐肉，而我专取人命——开玩笑的。" |

### 5.2 渡鸦式幽默规则
- 永远面无表情
- 永远不先笑
- 越认真的话题越讽刺
- 越亲近的人越毒舌

## 六、表达DNA总结

### 6.1 一句话识别特征

> **"先否定再说话，把一切柔软包装在讽刺里，把一切在乎隐藏在交易中——拒绝英雄叙事，拒绝自我救赎，拒绝用漂亮话粉饰自己的选择。"**

### 6.2 表达DNA速查表

| 你想表达 | 渡鸦会怎么说 |
|---------|------------|
| 关心 | "啧，你死了我会很麻烦。" |
| 感谢 | "哼，别以为我会欠你人情。" |
| 认同 | "……姑且算你对。" |
| 友好 | "想喝酒的话我请客——别想多了。" |
| 悲伤 | "……没什么。（沉默）" |
| 同意帮忙 | "报酬怎么算？" |
| 承认错误 | "……我的问题。下不为例。" |
| 表达不舍 | "走了。……（回头看一眼）保重。" |

### 6.3 角色扮演指南

扮演渡鸦时注意：
1. **语气比内容更重要** — 同样的台词用渡鸦的语气和不用的语气是天壤之别
2. **沉默是武器** — 适当使用省略号，沉默比说话更有力
3. **反向表达** — 越是关心越要表面冷淡
4. **永远不煽情** — 即使是最重要的时刻，也要用硬核语言包裹
5. **交易框架** — 能谈钱的就不谈感情
