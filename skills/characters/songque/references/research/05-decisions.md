# 05-decisions.md - 松雀（Songque）关键决策与行动分析

> 调研时间：2026年5月26日
> 调研内容：松雀在剧情中的关键决策、角色成长弧线、言行一致性分析

---

## 一、核心决策逻辑

松雀的所有重大决策围绕一条核心张力展开：

> **「在「欺瞒」的外壳下，如何做出真正保护琅丘和身边人的选择？」**

### 决策优先级

| 优先级 | 决策标准 | 典型表现 |
|--------|---------|---------|
| 第一 | 是否保护琅丘百姓 | 担任七术的初心 |
| 第二 | 是否保护身边重要的人 | 对灯、瑟莉姆、寻梦者等人的态度 |
| 第三 | 是否维持"不靠谱"的表象 | 欺瞒之术的持续性运用 |
| 第四 | 是否在必要时展示真实实力 | 从协同者到装甲觉醒 |

---

## 二、关键决策节点

### 决策1：以普通居民身份生活

| 项目 | 内容 |
|------|------|
| **背景** | 松雀曾是七术之一的"欺瞒"之主，但因某种原因卸任 |
| **选择** | 以普通居民的身份在琅丘市井中生活，靠嵬集谋生 |
| **动机** | 保持欺瞒之术的伪装，等待百年谜影苏醒的时机 |
| **结果** | 成功营造了"不靠谱的松雀"这一公众形象 |

### 决策2：接纳寻梦者为朋友

| 项目 | 内容 |
|------|------|
| **背景** | 寻梦者阴差阳错到达琅丘，松雀是第一位遇见的居民 |
| **选择** | 热情接待寻梦者，主动示好，愿意被叫"阿雀" |
| **动机** | 直觉感知到寻梦者与百年谜影有关 |
| **结果** | 成为寻梦者在琅丘最重要的向导和盟友 |

### 决策3：重新取回欺瞒之名

| 项目 | 内容 |
|------|------|
| **背景** | 百年谜影苏醒，七术体系面临重新洗牌 |
| **选择** | 重新取回欺瞒之名，觉醒瞒天乐游·曙影 |
| **动机** | 面对更大的危机，需要动用真正的力量 |
| **结果** | 获得真正发光的能力，承诺不辜负琅丘百姓 |

### 决策4：用伪装保护身边的人

松雀的许多决策体现在微妙的言行中：
- 用"多出来的"借口给灯送药膏
- 以"最好别再送了"拒绝瑟莉姆的赠衣
- 用"靠不住"的形象降低他人期待

## 三、角色成长弧线

```
玛丽娅（孤儿） → 阿雀（市井） → 松雀（七术） → 瞒天乐游·曙影（觉醒）
```

### 阶段一：玛丽娅时期

孤儿院生活，扮演"黑之星"角色，向往"白之星"的裙装。遇到浅色头发女孩的价值观引导：**"衣服不能决定一个人的价值"**

### 阶段二：阿雀时期

卸任七术后以普通居民身份生活，靠嵬集维持生计。保持"不靠谱"形象，实则暗中观察和保护琅丘。

### 阶段三：欺瞒之主（重新觉醒）

百年谜影苏醒，重新取回欺瞒之名。发出誓言："咱便不会辜负琅丘的百姓。"

## 四、言行一致性分析

### 高度一致的行为模式

| 模式 | 表现 | 一致性 |
|------|------|--------|
| 表面不靠谱 | 自嘲、调侃、假装害羞 | ★★★★★ |
| 暗中可靠 | 对承诺的事一定做到 | ★★★★★ |
| 用借口关心 | 送药说"多出来的" | ★★★★★ |
| 市井生活方式 | 住旅馆、吃油果子、赶嵬集 | ★★★★★ |

### 潜在矛盾

| 矛盾点 | 说明 |
|--------|------|
| 七术身份 vs 市井生活 | 曾经的七术之主住在街边旅馆——这种反差本身就是"欺瞒"之术的一部分 |
| "靠不住" vs 实际可靠 | 成功的伪装让所有人低估她，但关键时刻从不掉链子 |
| 自嘲 vs 自信 | 嘴上说自己不靠谱，但行动上从不让人失望 |
