# 05-decisions.md - 德尔塔（狂热蓝调Δ）关键决策与转折点

> 调研时间：2026年5月26日
> 命名说明：德尔塔是萝莎莉娅·阿琳（Rozaliya Olenyeva）在平行世界泡中的异时空同位体

## 一、决策逻辑框架

德尔塔的所有重大决策围绕一条终极公理和四条派生原则：

### 终极公理
> **「妹妹以命换命活下来的我，必须做点什么。」**

### 派生原则

| 优先级 | 决策标准 | 典型表现 |
|--------|---------|---------|
| 第一 | 是否对得起莉莉娅的牺牲？ | 活着并行动，不让莉莉娅的死白费 |
| 第二 | 是否能保护「与自己相关」的人？ | 无法放任平行世界的双子受伤害 |
| 第三 | 是否有效率/实际？ | 速通竞速型，不喜欢拖泥带水 |
| 第四 | 是否允许自己暴露脆弱？ | 拒绝谈论过去，防御性态度 |

## 二、关键决策

### 决策1：选择断后——让莉莉娅逃生（原世界泡）

| 项目 | 内容 |
|------|------|
| **背景** | 莉莉娅在实验中受重创。圣诞夜市中心遭袭，萝莎莉娅带莉莉娅撤离。 |
| **选择** | 选择留下断后，让莉莉娅拿身份卡去取装甲车独自逃离。与主线「背着逃命」不同——主动切断双子羁绊，采用理性的"舍一保一"策略。 |
| **她不知道的事** | 莉莉娅没真正离开。她去将崩坏兽DNA转移给重伤的萝莎莉娅后牺牲。 |
| **结果** | 萝莎莉娅融合莉莉娅基因后存活，成为「德尔塔」。 |
| **一致性** | ★★★★☆ 核心一致：保护妹妹的驱动力从未改变，只是策略从"一起活"变为"让她活"。 |

来源：崩坏冒险谭活动剧情、装甲故事 | 可信度：★★★★★

### 决策2：接受死亡，从崩溃中重生

| 项目 | 内容 |
|------|------|
| **背景** | 醒来发现莉莉娅已不在，身体中流淌妹妹的DNA，手持天鹅湖——但妹妹永远回不来了。 |
| **选择** | 被「摆渡人」开导后选择继续活下去，以代号「Δ」自称。 |
| **逻辑** | 表层：「妹妹以命换命活下来的我，不能浪费这条命。」深层：将悲伤转化为效率——不是走出来了，而是把悲伤锁进了行动的引擎里。 |
| **关键证据** | 「我得到了这份力量，却也因此失去了一切，呵，真是讽刺。」「我并不讨厌萝莎莉娅，我讨厌的是那个什么都没能做到的自己。」 |
| **一致性** | ★★★★★ 她用"用行动填补空洞"——从未宣称自己"走出来了"。 |

来源：米游社官方WIKI「狂热蓝调Δ」角色页 | 可信度：★★★★★

### 决策3：加入「摆渡人」组织

| 项目 | 内容 |
|------|------|
| **背景** | 原世界泡无法挽回地走向毁灭，失去了一切。 |
| **选择** | 加入可穿梭世界泡的组织「摆渡人」，执行各类回收任务。 |
| **逻辑** | 「妹妹以命换命活下来的我→必须做点什么」。德尔塔的冷漠是创伤后的重塑。 |
| **身份意义** | 「Δ」本身就是宣言：我不是过去的萝莎莉娅了。但「使用莉莉娅的天鹅湖」又暴露了从未真正放下的本质。 |
| **一致性** | ★★★☆☆ 表面不一致（声称是新身份，行为暴露未放下），但这是创伤的临床表现。 |

来源：米游社德尔塔简介、Fandom | 可信度：★★★★☆

### 决策4（核心转折）：越权带回平行世界双子

| 项目 | 内容 |
|------|------|
| **背景** | 在「崩坏国记」世界泡执行任务时，平行世界的阿琳姐妹面临生命危险。 |
| **选择** | **越权带回双子**——违反组织规定，将双子从危险中带出。 |
| **逻辑** | 冷硬外壳下的本质仍然是"保护"——与主线萝莎莉娅的底色完全一致。 |
| **代价** | 假期被缩减到原来的三分之一。 |
| **一致性** | ★★★★★ 嘴上说"别管闲事"，身体却在拯救。这是「言行不一致被行动推翻」的经典案例。 |

来源：rozaliya-perspective/01-writings.md、米游社 | 可信度：★★★★★

### 决策5：严格训练双子——作为「导师」

| 项目 | 内容 |
|------|------|
| **背景** | 双子加入摆渡人阵营后，承担训练责任。 |
| **选择** | 极其严厉的训练——不因为她们是"另一个自己/妹妹"而放水。 |
| **逻辑** | 三重动机：(1) 保护——「如果她们够强，就不会重蹈我的覆辙」(2) 投射——「萝莎莉娅，她就像过去的我一样」(3) 补偿——「我无法保护妹妹，至少要保护另一个世界的妹妹」 |
| **一致性** | ★★★★★ 严厉是另一种形式的爱。 |

来源：米游社官方WIKI、舰桥语音文本 | 可信度：★★★★★

### 决策6：在「星与你消失之日」中与Captainverse角色结盟

| 项目 | 内容 |
|------|------|

| **选择** | 与舰长及其他Captainverse角色合作，共同对抗威胁。 |
| **意义** | 从「孤独的刀」向「愿意合作的刀」转变。选择合作意味着信任——对她而言，信任比战斗更难。 |
| **一致性** | ★★★☆☆ 表面说「只是任务需要」，但行为上逐渐允许自己融入关系网络。 |

### 决策7：在「盛夏海滨游乐园」中流露隐藏情感

| 项目 | 内容 |
|------|------|
| **背景** | 德尔塔在梦境中扮演了「与妹妹重逢」的萝莎莉娅。 |
| **逻辑** | 不是主动选择，而是无意识情感的流露。在情境允许时，她允许自己短暂回到"有妹妹"的状态。 |
| **一致性** | ★★☆☆☆ 日常宣称"过去的已经过去了"，但在梦境中渴望毫无保留地流露。**不一致是最深刻的悲剧**——她可以欺骗所有人，甚至自己，但梦境揭穿了真相。 |

来源：萌娘百科、米游社剧情整理 | 可信度：★★★☆☆

## 三、四大转折点

### 转折点1：莉莉娅牺牲
天真元气的萝莎莉娅 → 失去信念 → 人格重构为德尔塔

### 转折点2：被摆渡人拯救并加入
失去信念的幸存者 → 接受代号「Δ」 → 从"被动幸存"转为"主动行动"

### 转折点3：越权带回双子
效率至上的执行者 → 违反规则拯救双子 → 暴露真实本质，接受导师角色

### 转折点4：融入Captainverse团队
组织内的执行者 → 与舰长等人建立信任关系 → 从"孤独的刀"走向"愿意与人联结"

## 四、核心矛盾

| 矛盾对 | 内容 |
|--------|------|
| 「我是德尔塔」vs「我仍是萝莎莉娅」 | 宣称新身份，但使用天鹅湖、保护双子、梦境中重温过去 |
| 「我不在乎」vs「我无法放任」 | 嘴上说不关心，遇到"妹妹"相关线索时毫不犹豫介入 |
| 「过去已经过去」vs「我从未走出来」 | 拒绝谈过去，但"拜托了天鹅湖"暴露每一天都在与莉莉娅告别 |
| 「独立执行者」vs「渴望被理解」 | 告诉舰长"你查不到的"，却又主动提及"失去一切" |
