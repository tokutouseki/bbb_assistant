## 二、德尔塔角色时间线

### 角色基本信息

| 维度 | 内容 |
|------|------|
| **全名** | 德尔塔·阿琳（Delta Olenyeva），代号 DELTA |
| **本体系** | 萝莎莉娅·阿琳的平行世界同位体 |
| **装甲名** | 狂热蓝调Δ（Fervent Tempo Δ） |
| **首次出场** | v4.3（2020年9月26日）「崩坏冒险谭」活动 |
| **装甲类型** | S级 异能属性 物理伤害 |
| **武器** | 双持大剑「睡美人之梦」/ 天鹅湖 |
| **中配CV** | 多多poi（与萝莎莉娅相同） |
| **日配CV** | 古贺葵（与萝莎莉娅相同） |
| **代表色** | 粉蓝对称（比主线双子更沉稳的色调） |
| **核心机制** | 粉蓝双色动能条 → 蓄力进入「狂热状态」 |
| **必杀技** | 「旧日残像」——防御反击，完美弹反触发时空断裂 |

## 四、人格对比：德尔塔 vs 主线萝莎莉娅

| 维度 | 主线萝莎莉娅 | 德尔塔·阿琳 |
|------|-------------|-------------|
| 核心人格 | 元气笨蛋、天真热忱、话多 | 冷酷成熟、沉默寡言、理性 |
| 情感表达 | 外放式——大声哭、大笑、大喊 | 压抑式——平静、克制、回避 |
| 与莉莉娅的关系 | 两人都活着，双子共生 | 莉莉娅已死，独自背负 |
| 战斗风格 | 单持大剑+装甲拳击，冲在前面 | 双持大剑+防御反击，计算每一击 |
| 说话方式 | 感叹号满天飞，「乌拉！」 | 陈述句为主，句号收尾 |
| 归属感 | 属于伏特加女孩、属于休伯利安 | 不属于任何「家」，只有代号和组织 |
