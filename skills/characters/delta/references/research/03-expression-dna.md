## 四、语气特征

### 总体基调
- **冷静慵懒**：语速偏慢，声音偏沉——和萝莎莉娅的元气高亢形成180度反差
- **句尾下沉**：陈述句收尾，感叹句极少——与萝莎莉娅句句感叹号相反
- **省略号连接**：常用「…」制造停顿和留白
- **讽刺底色**：「呵，真是讽刺。」——用冷笑消解情感密度

### 渐进式切换模型

```
日常状态：慵懒、冷静、话少
  → 被触及敏感话题：防御升级 → 反问/冷读/转移
  → 战斗状态：语音变短、指令清晰、略带杀气
  → 罕见破防：口是心非、关心泄露、核心自白
```

### 战斗语气
- 偏冷的命令式——「碾碎它们吧。」
- 防御反击时带一丝莉莉娅的语调——「shield，lucky attack」
- 核心必杀技带颤抖的情感——「拜托了天鹅湖……让这一切结束吧。」

## 五、情感表达方式

### 关心伪装机制
先表达关心 → 再否认/修正
> 「新款式的装甲，他也许会喜欢吧……呃，我是说谢谢。」
> 「今天居然没有黑眼圈了，看来你昨晚睡得还不错。」（不否认，但也不解释）

### 间接悲伤
从不直接说"我难过"，而是通过：
- 自嘲：「呵，真是讽刺。」
- 转移：「你还可以找回你所失去的东西，这一点上你远比我更幸运。」
- 回避：「别白费力气了，你查不到的。」

### 冷式愤怒
从不吼叫。愤怒时：
- 语气变冷
- 语速变慢
- 用反问代替爆发

### 黑色幽默
> 「想摸摸我的尾巴？当然可以，只要你能做得到的话。」
> 「你这船还挺不错的嘛…怎么样，要不要和我换着开几天？」

### 情感泄露的信号词
| 信号 | 含义 |
|------|------|
| 「也许」+停顿「……」 | 即将暴露真心 |
| 「呃」+修正 | 口是心非的典型信号 |
| 主动提及 | 反常——对过去/感受的稀缺提及 |

| 模式 | 名称 | 特征 | 典型台词 |

| 5 | 战斗机器 | 指令式、干脆 | 「碾碎它们吧。」 |

## 七、核心矛盾

| 矛盾 | 语言表现 |
|------|---------|
| 拒绝过去 vs 无法放下 | 自称「德尔塔」≠萝莎莉娅，但战斗时呼唤「天鹅湖」 |
| 声称不在乎 vs 行动关心 | 「别白费力气了」vs 关注舰长的睡眠 |
| 独立执行者 vs 渴望被理解 | 「你查不到的」vs 主动提及「失去一切」 |
| 冷硬外壳 vs 保护本能 | 「这是任务」vs 越权救双子 |
