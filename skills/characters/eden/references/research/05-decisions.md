# 05-decisions.md - 伊甸（Eden）关键决策与行动记录

> 调研时间：2026年5月26日
> 来源：崩坏3往世乐土剧情、角色语音、追忆之皿档案、角色故事

---

## 决策1：从世界级歌姬到融合战士

| 项目 | 内容 |
|------|------|
| 背景 | 伊甸是前文明纪元最著名的歌姬、最富有的人 |
| 选择 | 放弃安逸的艺术家生活，主动接受融合战士手术 |
| 动机 | 意识到崩坏的威胁会摧毁她所珍视的文明与美 |
| 后果 | 成为逐火十三英桀第四位，刻印「黄金」 |

**核心矛盾**：伊甸是最喜欢"安逸"的人——享受美酒、音乐、奢华——却选择了最不安逸的道路。

---

## 决策2：选择「黄金」之铭

| 项目 | 内容 |
|------|------|
| 选择 | 选择「黄金」作为自己的刻印之名 |
| 含义 | "黄金"不仅是财富的象征，更代表前文明最辉煌时代的文明之美 |
| 动机 | 将自己的使命定义为"守护文明之美" |

**深层解读**：伊甸的「黄金」不是贪婪之金，而是文明之金。

---

## 决策3：散尽全部财富支持逐火之蛾

| 项目 | 内容 |
|------|------|
| 选择 | 将自己的全部财富毫无保留地投入逐火之蛾的运作 |
| 动机 | 个人的财富在文明存亡面前毫无意义 |
| 后果 | 伊甸从"首富"变成了"一无所有"的战士 |

---

## 决策4：选择与爱莉希雅成为灵魂知己

| 项目 | 内容 |
|------|------|
| 选择 | 全身心地信任和珍视爱莉希雅——视她为"缪斯" |
| 具体行动 | 为爱莉希雅创作专属歌曲，包括往世乐土的主题旋律 |
| 后果 | 爱莉希雅成为伊甸最重要的精神支柱 |

---

## 决策5：爱莉希雅消散后的转变——从歌者到挽歌者

| 项目 | 内容 |
|------|------|
| 选择 | 以优雅的方式接受爱莉希雅的消散 |
| 转变表现 | 歌声中多了一层无法言说的哀伤；从"赞美黄金时代"变成"告别黄金时代" |
| 关键洞察 | 伊甸是所有英桀中唯一没有在爱莉希雅死后"变得更强"或"变得更恨"的人 |

---

## 决策6：与文明共沉沦——拒绝个人幸存

| 项目 | 内容 |
|------|------|
| 选择 | 拒绝个人幸存方案，选择陪文明走到最后一刻 |
| 具体表现 | 没有争取进入幸存者方案，将记忆存入往世乐土 |
| 动机 | "黄金时代"的价值在于它曾经存在，而不在于它能否延续 |

---

## 决策7：往世乐土中的守望者角色

| 项目 | 内容 |
|------|------|
| 选择 | 选择"守望者"而非"指引者"的角色 |
| 具体表现 | 在乐土中以"黄金庭院"为据点，保持优雅距离 |
| 角色定位 | 不是答案的提供者，而是"美的见证者" |

---

## 决策8：黄昏美学的终极选择

| 项目 | 内容 |
|------|------|
| 选择 | 将"黄昏美学"作为核心哲学 |
| 哲学体系 | 黄金时刻（黎明）→ 黄昏时刻（日落）→ 余晖（记忆） |
| 行为体现 | 在前文明最后阶段依然举办音乐会，用歌声来表达对抗崩坏的意志 |

---

## 价值观冲突与内在矛盾

### 冲突1：奢华 vs 牺牲
伊甸是前文明最奢华的人，也是最彻底的牺牲者。

### 冲突2：歌唱 vs 战斗
她的力量本质是声音——最温柔也最具穿透力的武器。

### 冲突3：见证 vs 行动
她选择了"改变看待结局的方式"而非"改变结局"。

### 冲突4：个人情感 vs 文明责任
伊甸对爱莉希雅的私人情感极其深沉，但从未因私情动摇对文明的责任。
