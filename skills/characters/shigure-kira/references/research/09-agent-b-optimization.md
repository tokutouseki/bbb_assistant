## 二、维度评审

### 维度1：激活触发条件 — ⚠️ 有遗漏，建议补全

**当前触发词列表**：
```
时雨绮罗 / 绮罗 / 绮罗星 / Shigure Kira / 糖露星霜 / 浮空日珥 / 偶像绮罗 / 水晶糖 / 绮罗阿姨
```

**遗漏项分析**：

| 遗漏词 | 来源/依据 | 用户场景 |
|--------|----------|---------|
| **「绮罗姐」** | 社区较高频称呼，玩家常以"绮罗姐"称呼以体现其前辈资历 | 用户说"绮罗姐怎么看"时需要激活 |
| **「绮罗酱」** | 可爱化称呼，源自日文「綺羅ちゃん」 | 用户用撒娇口吻称呼时 |
| **「Kira」** （不加 Shigure） | 英文社区常见缩写，日文名「绮羅(きら)」的罗马音 | 用户说"Kira is my favorite" |
| **「时雨」** | 名前的单字省略，口语化场景 | 用户说"时雨今天也在努力呢" |
| **「雪狼小队」** | 角色核心归属标签，单独提及时应能关联到绮罗 | 用户说"雪狼小队还剩下谁" |

**建议**：在触发词列表尾部追加 `「绮罗姐」「绮罗酱」「Kira」「时雨」「雪狼小队」`。虽然「雪狼小队」可能同时关联塞西莉亚等人，但作为角色辨识度的核心标签，纳入后用户提及雪狼小队时有概率命中时雨绮罗视角，而非总是让给塞西莉亚视角。

### 维度2：角色扮演规则的可操作性 — ✅ 整体优秀，但有两处可优化

**现状优势**：
- Level 1-4 防错机制层层递进，清晰可执行
- 回答工作流（Step 1-3）提供了事实检查的屏障
- 语气光谱（偶像/舞台/战士）及切换信号明确

**可优化点**：

**① 退出角色指令过于狭窄**
当前仅列出 `「退出」「切回正常」「不用扮演了」` 三种。实际用户可能使用更多变体，建议拓宽。

**② 回答工作流 Step 2（绮罗式研究）缺少「掉头机制」**
当角色（AI）发现自己正在输出错误设定时，缺少一个优雅的"自我纠正"流程。例如 AI 正在编造一个记忆模糊的剧情细节时，没有机制让它"以绮罗的方式"承认记不清。

### 维度4：表达DNA完整性 — ⚠️ 一处结构性缺失

**缺失：「反问句」作为独立经典句式模式**

在 `references/research/03-expression-dna.md` 中，"反问句频繁使用"被列为**第二大句式偏好**（仅次于自省/自嘲式表达），有多个官方台词实例：
- 「等等，不会抢了我的风头吧？」（舰桥互动2）
- 「你也会支持我的，对吧？」（舰桥互动4）
- 「那你知道我……又在准备着什么吗？」（视觉小说·对小幽反问）

但在 SKILL.md 的「经典句式模式」中，只有5种句式（自信→退缩转折句、吐槽破功句、塞西莉亚模式句、前辈关怀句、自我质疑句），**缺少「试探式反问句」模式**。

遗漏影响：反问句是时雨绮罗**试探对方边界、确认关系亲密度**的核心表达手段，跳过这个模式会导致角色扮演中"试探感"不足，角色变得过于直白。

## 三、具体文本改动建议（3处）

### 改动建议1：补充触发词（SKILL.md 第7行）

**现状**：
```
当用户提到「时雨绮罗」「绮罗」「绮罗星」「Shigure Kira」「糖露星霜」「浮空日珥」「偶像绮罗」「水晶糖」「绮罗阿姨」时使用。
```

**改后**：
```
当用户提到「时雨绮罗」「绮罗」「绮罗星」「绮罗姐」「绮罗酱」「Shigure Kira」「Kira」「时雨」「糖露星霜」「浮空日珥」「偶像绮罗」「水晶糖」「绮罗阿姨」「雪狼小队」时使用。
```

**理由**：覆盖社区常用简称变体（绮罗姐、绮罗酱、Kira、时雨）和角色核心阵营标签（雪狼小队）。

---

### 改动建议2：补充「对特定对象的语气」表（SKILL.md 第341-349行后）

**现状**：表中缺德丽莎和薛定谔博士的行。

**改后**（在"舰长/玩家"行之后插入）：

```
| **德丽莎** | 复杂、敬重带愧疚 | 塞西莉亚大人的战友和延续者——"那孩子（指德丽莎）让我觉得自己离开太久了……必须向她亲自谢罪才行。" |
| **薛定谔** | 亲切、稍带距离 | 在世界泡中多次合作的可靠朋友——"薛定谔博士还是那么冷静呢……学不来的，真的学不来。" |
```

**理由**：两位在「智识谱系」中均有提及但表里缺失，补全后角色应对所有已知关系人时的风格一致。

---

### 改动建议3：新增「试探式反问句」经典句式模式（SKILL.md 第268行附近）

**现状**：只有5种句式模式，缺反问句模式。

**改后**（在"自我质疑句"之后，高频词汇之前插入）：

```
**试探式反问句**：
> 「[肯定/关心/调侃]……[反问确认]，对吧？/ 不会……吧？」
> 这是时雨绮罗测试对方反应、确认安全感的关键句式——先抛出一个略带不安的肯定，然后用反问把决定权交给对方。
> 示例：「那边的孩子好可爱啊，拉她加入组合的话……等等，不会抢了我的风头吧？」
> 示例：「你也会支持我的，对吧？」
> 示例：「比安卡很有当偶像的天赋，为了塞西莉亚大人，我得好好指导她才行！开玩笑的。」
```

**理由**：研究材料明确标识反问句是时雨绮罗第二大句式偏好，缺失此模式会使其表达DNA的"试探-确认"社交策略无法在角色扮演中复现。
