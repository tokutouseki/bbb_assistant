## 二、高频词汇与口癖

### 标志性口癖

| 口癖 | 使用频率 | 语境说明 |
|------|---------|---------|
| 「喵」/「喵~」 | 极高 | 语尾或独立感叹词，猫娘标志性口癖 |
| 「好诶！」 | 高 | 听到好消息/赚到钱时的欢呼，语气高扬 |
| 「发财啦发财啦！」 | 高 | 获得收益时的经典连呼 |
| 「本喵」 | 高 | 常用自称，替代「我」 |
| 「惨啦惨啦」/「完蛋啦」 | 中高 | 遇事慌乱时的重复式连呼 |
| 「溜了溜了」 | 中 | 见势不妙准备逃跑时的经典台词 |

### 高频语气词

| 语气词 | 频率 | 效果 |
|--------|------|------|
| 「啦」 | 最高 | 语尾几乎句句带"啦"，松弛随意 |
| 「诶」 | 高 | 惊讶、困惑时开口词 |
| 「嘛」 | 中高 | 缓和语气、自我安慰 |
| 「哇」 | 中 | 惊喜感叹 |
| 「哎哟」 | 中 | 抱怨、撒娇 |
| 「唔」 | 中低 | 思考、犹豫 |
| 「嗷」 | 低 | 被吓到或被打到的痛呼 |

### 核心词汇体系

| 词汇 | 含义 |
|------|------|
| 「钱」/「赚」/「生意」 | 最高频核心词 |
| 「情报」 | 用来交换/贩卖的信息 |
| 「打折」/「优惠」/「八折」 | 商铺经营话术 |
| 「赊账」 | 允许熟人先拿货后付钱 |
| 「跑路」/「逃跑」 | 形容自己最擅长的技能（自嘲） |
| 「划算」/「血亏」 | 对交易的性价比评价 |

## 三、句式特征

| 维度 | 特征 |
|------|------|
| 短句占比 | 约55%——英桀中短句占比最高 |
| 感叹句占比 | 约30%——英桀中感叹句最多 |
| 语尾模式 | 「啦~」最常用；「嘛」认命感；「呗」商量语气；「喵」萌化语尾 |
| 波浪号 `~` 使用 | 日常对话几乎句句有，严肃话题完全消失 |
| 重复连呼 | 「发财啦发财啦」「惨啦惨啦」「来了来了」——高频口癖特征 |

## 四、说话节奏

| 节奏类型 | 占比 | 触发条件 |
|---------|------|---------|
| 快节奏·兴奋 | 40% | 看到好东西、赚到钱、遇到好事 |
| 慢节奏·心虚/讨好 | 30% | 想套近乎、有事求人 |
| 急促·慌乱 | 20% | 遇到危险、被责备——连珠炮+结巴 |
| 缓慢·认真 | 10% | 涉及同伴安危、英桀使命等严肃话题 |

**主导节奏范式：讨好铺垫→快速诉求**
> 铺垫：主动示好、戴高帽→过渡：用商业关系转化→诉求：快速抛出目标→收尾：不等回应先跑

## 六、情感表达：关心伪装机制

| 真实意图 | 实际表达 | 伪装机制 |
|---------|---------|---------|
| 担心你 | 「我这有个保命的小道具，友情价卖给你」 | 用"卖"遮掩"给" |
| 你受伤了 | 「上次进货多了一些伤药，便宜点处理给你」 | 用"清库存"遮掩关心 |
| 我支持你 | 「本喵会在后方给你准备好物资——要收费的」 | 嘴上说收费，实际会免费 |

| 舍不得你 | 「下次光顾给你打八折！一定要活着回来啊」 | 用打折遮掩不舍 |

## 七、确定性表达模式

**核心规律：对自己不确定，对生意极确定**
> 关于自己实力 → 「我大概......可能......应该......打不过吧......」
> 关于商品价格 → 「这个绝对是全网最低价！」
> 关于同伴安危 → 「他们一定不会有事的！——因为他们可是英桀啊！」

## 八、表达DNA核心公式

```
帕朵式表达 = 
  [猫化前缀/自称] 
  + [商业逻辑框架] 
  + [自嘲/示弱] 
  + [拉近距离]

```
