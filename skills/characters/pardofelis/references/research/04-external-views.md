# 帕朵菲莉丝（Pardofelis）——「空梦」之铭 · 他者视角与评价

> 调研日期：2026-05-26

---

## 一、其他英桀对帕朵的评价

### 1.1 爱莉希雅
- **关系定位**：拯救者/最重要的人
- **评价**：爱莉希雅眼中的帕朵是"虽然胆小但有着独特勇气"的存在
- **分析**：爱莉希雅是唯一一个从一开始就相信帕朵价值的人。她力排众议让帕朵成为英桀第十三席，理由是——英桀不仅需要最强的人，也需要一个代表普通人的存在

### 1.2 伊甸
- **关系定位**：慈爱宠溺的"金主"
- **评价**：伊甸对帕朵极为纵容和宠爱。帕朵形容伊甸是"人美钱多，从来不还价"的完美客户
- **地位分析**：帕朵"偷遍英桀"但唯独不敢偷伊甸的东西，因为伊甸会笑着送给她——这个细节揭示了伊甸对帕朵的溺爱程度

### 1.3 格蕾修
- **关系定位**：玩伴/妹妹
- **评价**：格蕾修称帕朵为"帕朵姐姐"
- **细节**：格蕾修喜欢玩帕朵的尾巴，帕朵对格蕾修展现出了难得的温柔和保护欲

### 1.4 阿波尼亚
- **关系定位**：慈爱长辈
- **评价**：阿波尼亚以"妈妈"的形象关爱所有英桀
- **帕朵回应**：帕朵称阿波尼亚为"阿波尼亚妈妈"

### 1.5 凯文
- **关系定位**：领袖/敬畏对象
- **帕朵态度**：在凯文面前不敢大声说话，但认可凯文"从不拖欠报酬"
- **距离感**：在所有英桀中，帕朵对凯文保持最大的距离和敬畏

### 1.6 千劫
- **关系定位**：不能惹的对象
- **帕朵态度**：怕千劫的暴脾气，但评价他是"给钱挺爽快"的客户
- **相处模式**：从不去主动招惹千劫，保持了商业化的尊敬

### 1.7 梅比乌斯
- **关系定位**：手术执行者/有点怕
- **帕朵态度**：对梅比乌斯既感激（做了超变手术）又害怕（怕被当成实验品）

## 二、角色特质外部印象

| 特质 | 外部观察描述 |
|------|------------|
| 生存哲学 | 「凡人中的凡人」——帕朵是十三英桀中唯一一个没有超凡气质的角色 |
| 商人本色 | 表层是贪财市侩，深层是用"交易关系"构建安全社交距离的防御机制 |
| 胆小的勇气 | 在关键时刻总能超越自己的胆小本性 |
| 猫的意象 | 帕朵不是"像猫"，她就是猫——猫耳、猫尾、猫的习性、猫的生存哲学 |

## 三、角色功能定位

| 功能 | 说明 |
|------|------|
| 反差角色 | 在严肃悲壮的英桀故事中提供轻松幽默的调剂 |

| 连接者 | 通过她的商店，连接所有英桀的日常社交 |
| 幸存者符号 | 她的"幸运"和"逃跑"最终却让她成为了唯一逃出乐土的记忆体 |
