# 帕朵菲莉丝（Pardofelis）——「空梦」之铭 · 决策与行动记录

> 调研日期：2026-05-26

---

## 一、关键人生决策

### 1.1 被爱莉希雅带离黄昏街
- **决策性质**：被动接受改变
- **背景**：黄昏街流浪孤儿，被爱莉希雅发现并带离
- **结果**：从此踏入英桀之路
- **体现**：帕朵的人生转折点不是自己主动选择的，而是被"幸运"选中

### 1.2 接受超变手术
- **决策性质**：被迫但接受的生存选择
- **背景**：要留在逐火之蛾就必须接受融合战士手术
- **结果**：成为猫型融合战士，获得「空梦」能力
- **体现**：为了活下去而接受改造，而非追求力量

### 1.3 成为英桀第十三席
- **决策性质**：被动接受
- **背景**：爱莉希雅力排众议推荐
- **结果**：正式成为逐火十三英桀成员
- **体现**：帕朵从不认为自己"配得上"英桀的称号

---

## 二、往世乐土中的关键选择

### 2.1 选择帮助雷电芽衣
- **场景**：芽衣进入往世乐土后
- **决策**：以商人的身份提供情报和物资
- **动机**：表面是为了交易利益，实际是信任芽衣（因为芽衣得到了爱莉希雅的认可）

### 2.2 选择留在乐土而非逃跑
- **场景**：侵蚀律者入侵往世乐土
- **决策**：没有选择独自逃逸，而是留下来对抗
- **动机**：为了保护同伴
- **体现**：帕朵最重要的性格转折——从"本能求存"到"为同伴而战"

### 2.3 向芽衣透露核心情报
- **场景**：往世乐土危机深入
- **决策**：在没有要求回报的情况下提供重要情报
- **体现**：突破了"只做交易"的原则，真正信任了芽衣

### 2.4 记忆体逃离乐土
- **场景**：往世乐土崩塌
- **决策**：选择逃离而非消散
- **结果**：成为极少数逃出乐土的英桀记忆体
- **体现**：「空梦」的最终印证——在不可能中找到机会

---

## 三、行为模式总结

| 模式 | 描述 |
|------|------|
| 生存优先 | 所有决策的第一考量：能不能活下来 |
| 以退为进 | 看似软弱退缩，实则为自己留出最佳应对空间 |
| 交易缓冲 | 用商业关系保持社交距离，避免情感过载 |
| 关键时刻不掉链子 | 平时胆小，但该上的时候绝不退缩 |
| 用轻松抵消沉重 | 在最悲伤的场合也能找到轻松的角度 |

---

## 四、价值观排序

```
1. 生存——活下去是最重要的
2. 快乐——活着就要开心
3. 交易——用商业维系人际关系
4. 友谊——表面冷淡但内心看重同伴
5. 乐观——相信"幸运"会站在自己这边
```
