# 全量日常调度技能

## When to Use

当用户请求以下操作时使用此技能：
- "执行今日任务"、"全自动"、"日常全任务"
- "full operation"、"full"、"全部任务"
- "帮我做完今天的日常"
- 需要一键完成当日所有可做的崩坏3任务

## 概述

此技能调用 hongkai_done 的 `full_operation.py` 脚本，根据当前星期几自动编排并执行当日任务组合。

每周任务安排：
| 星期 | 执行内容 |
|------|----------|
| 星期一 | 每日任务 + 任务减负 + 每周礼包 + 往世乐土 |
| 星期二 | 每日任务 + 战场 + 模拟作战室 |
| 星期三 | 每日任务 + 战场 |
| 星期四 | 每日任务 + 战场 |
| 星期五 | 每日任务 |
| 星期六 | 每日任务 |
| 星期日 | 每日任务 + 舰团贡献 + 模拟作战室 |

## 技能流程

此技能为单步执行，无需分阶段。

**步骤 1** — 调用 `run_hongkai_task` 执行全量调度

调用 `run_hongkai_task task="full_operation"` 启动全量日常调度脚本。该脚本会：
1. 请求管理员权限（如未提权）
2. 保存当前日期时间
3. 根据星期几确定任务列表
4. 聚焦崩坏3游戏窗口
5. 按顺序执行每项任务

脚本会弹出新控制台窗口，用户可观察执行进度。最长等待 600 秒。

**步骤 2** — 报告结果

根据工具返回结果向用户汇报：
- 完成情况（成功/失败/超时）
- 执行的日志摘要

## 注意事项

1. **需要管理员权限**：脚本会自动请求 UAC 提权，请在弹出提示中选择"是"
2. **游戏必须已打开**：确保崩坏3游戏窗口在前台运行
3. **执行时间较长**：周一（含乐土）可能需要 20-40 分钟，其他日子约 5-15 分钟
4. **新窗口弹出**：脚本会在新控制台窗口中运行，方便观察进度
5. **每周礼包仅周一**：`everyweek_gift` 仅在周一触发，其他天不会领取
